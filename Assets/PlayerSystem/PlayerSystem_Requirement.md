# 맵1 DayDream — 캐릭터 베이스 (Character Base) 요구사항

> 출처: 요구사항 명세서 v1.0 (기획안 v.1 + 레벨 디자인 피드백 반영 확정본)
> 작성: 송원석 · 2026-07-22
> 발췌 범위: "캐릭터 베이스" 업무구분 항목만 정리 (원문 그대로, 왜곡 없음)

## 공통 계산 기준
- 중력 -9.81 (Unity 기본)
- 공중 이동 속도 = 지상 속도 × 0.6
- 1 Unit = 1m
- 공통식: `v0 = √(2 × 9.81 × H)` · 체공 `t = 2 × √(2H / 9.81)` · 수평 도달 `D = 지상속도 × 0.6 × t`

---

## 1. 공통 규격 — 중력/공중제어 계수 확정
비고: 전 수치 계산의 기준
- [기준] 중력 -9.81 (Unity 기본), 커스텀 중력 미사용
- [공중 이동 속도] 지상 속도 × 0.6
- [근거] 세모 점프 H=2.0 → 체공 t=2√(2H/g)=1.28s → 5.0×0.6×1.28=3.83U ≈ 기획안 가로 4U
- [지시] 이 두 값을 바꾸면 명세서의 모든 도달 거리 수치가 무효

## 2. 도형 스탯 — 도형 3종 스탯 데이터 정의
비고: ScriptableObject 권장
- [구] 이속 7.0 / 점프 H 1.6U / 질량 1.5 / 마찰 0.1
- [세모] 이속 5.0 / 점프 H 2.0U / 질량 1.0 / 마찰 0.8
- [네모] 이속 3.5 / 점프 H 1.2U / 질량 3.0 / 마찰 0.5
- [지시] 스탯을 코드가 아닌 데이터 에셋으로 분리, 도형 추가 시 코드 수정 불필요하게

## 3. 점프 — 목표 높이 기반 초속도 역산
비고: AddForce 금지
- [처리] `rb.velocity.y = Mathf.Sqrt(2f * 9.81f * H)` (대입, 가산 아님)
- [사유] AddForce는 질량이 개입해 레벨 설계 수치와 어긋남
- [적용 범위] 기본 점프, 트램펄린, 시소, 강제 점프 전부 동일 방식
- [입력] Inspector에는 힘이 아니라 목표 높이 H(Unit)를 노출

## 4. 점프 — 도형별 점프 도달 규격표
비고: 레벨 배치 기준표
- [구] 높이 1.60U / 체공 1.14s / 가로 4.80U
- [세모] 높이 2.00U / 체공 1.28s / 가로 3.83U
- [네모] 높이 1.20U / 체공 0.99s / 가로 2.08U
- [특이점] 구는 점프가 낮은데 속도가 빨라 가로 도달은 가장 김

## 5. 이동 — 공중 제어 처리
비고: 계수 0.6 고정
- [조건] isGrounded == false
- [처리] 수평 입력 가속을 지상 속도의 0.6배로 제한
- [예외] 트램펄린/실타래 발사 직후 0.2s는 입력 무시 (궤적 보존)
- [검증] 세모 제자리 점프 후 가로 도달이 3.8~4.0U인지 실측

## 6. 물리 — 도형별 물리 머티리얼 적용
비고: 미끄럼틀/이동발판 기믹의 전제
- [구] 마찰 0.1 / 반발 0 → 경사 활강, 이동 발판 위 미끄러짐(의도된 특성)
- [세모] 마찰 0.8 / 반발 0 → 꼭짓점 고정, 흔들리는 발판 위 안정
- [네모] 마찰 0.5 / 반발 0 → 조향 안정
- [주의] 미끄러짐은 버그가 아니라 구의 기능. QA에 사전 공지

## 7. 판별 — 도형 종류 판별 공통 컴포넌트
비고: CompareTag 하드코딩 금지
- [구성] 캐릭터 루트에 도형 종류를 반환하는 컴포넌트 부착
- [조회] 기믹은 Collider → 루트 → 도형 종류 순으로 조회
- [사유] 전 기믹이 누가 닿았는지 알아야 차등 처리 가능
- [확장] 도형 추가 시 기믹 코드 수정 없이 동작해야 함

## 8. 레벨 규격 — 메인 경로 네모 기준 설계 규칙
비고: 필수 규칙 (LD-01)
- [규칙] 필수 통과 경로의 틈은 2.0U 이하, 턱은 1.1U 이하 (네모 한계 2.08U / 1.20U에서 여유 차감)
- [예외] 지름길, 숨겨진 길, 보상 경로만 특정 도형 전용 규격 허용
- [검증] 그레이박스 완성 시 네모 단독 전 구간 완주 테스트 통과가 머지 조건
- [사유] 맵 완성 후 네모 통과 불가 구간을 발견하는 사고 방지
