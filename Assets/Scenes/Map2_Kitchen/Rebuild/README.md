# 맵2 주방 리빌딩 3차

Unity 버전은 **2022.3.62f3**이다.

## 플레이

1. Unity에서 `Assets/Scenes/Map2_Kitchen/Rebuild/Scenes/Map2KitchenPlayable.unity`를 열고 Play를 누른다.
2. WASD로 이동하고 마우스로 시점을 돌린다. Space는 점프, Tab은 도형 전환, E는 열쇠 상호작용에 사용한다.
3. 검토용 숫자 키 1~7로 각 챕터 입구를 바로 확인할 수 있다.
4. 챕터 7에서 열쇠를 얻어 상단 문을 열고 배출구로 내려가면 팀 맵3 씬이 로드된다.

## 폴더

- `Scenes`에는 플레이 씬 `Map2KitchenPlayable`과 제작용 씬 `Map2KitchenDraft`, `Map2KitchenDetail`이 있다.
- `Scripts`에는 맵 전용 실행 코드, `Editor`에는 제작 및 검증 도구가 있다.
- `Art`에는 메시와 텍스처, `Materials`에는 재질이 있다.
