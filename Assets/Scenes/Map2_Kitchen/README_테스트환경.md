# KitchenMapV3 — 팀 기본 시스템 재구성 후보

2026-09-15. 아직 전체 플레이 검증 중인 로컬 후보다. 이전 업로드본의 시험 통과 수치를 이 버전의 결과로 사용하지 않는다.

## 실행

Unity 2022.3.62f3, 팀 저장소의 PlayerSystem·DoorSystem·DreamThreadSystem·RespawnSystem·RailCartSystem·WindupAxleSystem이 필요하다. 기존 작업 씬을 보관한 뒤 새 Empty 씬 하나를 `Assets/KitchenMapV3/Scenes/` 아래 저장한다.

1. `Tools/KitchenMapV3/2. Build All (팀 기믹)`.
2. `Tools/KitchenMapV3/3. Setup Play (팀 플레이어·카메라)`.
3. 콘솔 오류를 확인하고 씬을 저장한 뒤 Play.
4. WASD 이동, Space 점프, Tab 전환. 카메라는 팀 `PlayerFollowCamera`의 마우스 회전이다. Escape는 커서 해제, 클릭은 다시 잠금이다.

기존 자체 런타임이 들어 있는 씬에 덮어 적용하지 않는다. 제거된 스크립트의 Missing Script가 남지 않도록 새 씬을 생성한다.

## 실제 구성과 변경 범위

- 팀 생성 메뉴가 만든 플레이어·스탯·마찰·카메라를 사용한다. 자체 카메라, WallSlip, GroundContactRelay는 제거했다.
- 시작/출구는 팀 ExitWeightPlate와 연결된 문을 사용한다. 기본 임계 2.75와 열림 유지 설정을 보존한다. 기존 P5 세 판/시간창 퍼즐과 다른 규칙이다.
- 체크포인트는 팀 RespawnZone/RespawnController다. 순차 잠금은 없다. 맵 배치용 트리거 크기는 6×3×6으로 설정한다. 낙하 추가 높이는 팀 기본 10을 유지한다.
- 실 앵커 6개, 줄다리 2개는 팀 생성기를 사용한다. 아일랜드 건넘은 줄다리이며 가짜 카트 도킹이 아니다. 마당 줄다리는 아래 보완에 따라 장식 건조대 구역의 9.5U 경간으로 재배치했다.
- 동쪽 바닥에 팀 레일 카트와 연결된 태엽축을 배치했다. 카트는 기존 아일랜드 도킹 퍼즐의 완성본이 아니다.
- 팀 레버·문·패드 세트를 배치했다. 수위·투석기 등 모든 과거 기획 기믹이 구현된 것은 아니다.
- CP05·CP07의 낙하 복귀가 윗층에 착지하는 문제를 발견해 위치를 조정했다. CP07은 능선과 같은 높이의 5×4.2 착지대를 추가했다.

## 검증 한계 / 업로드 보류

Windows 후보 빌드는 성공했다. 기본 플레이 모드 검사 22건은 통과했으나 이는 전체 경로 완주 증거가 아니다. API 점프와 무게판 접촉 검사에는 검증용 위치 이동을 사용했다.

초기 체크포인트 검사에서 CP05·CP07의 추락 복귀가 실패해 배치를 보완했고, 집중 재검사 34건을 통과했다. 팀 리스폰 코드의 kinematic 속도 대입 경고가 재현되며 팀 코드는 수정하지 않았다.

두 주요 계단 진입로는 경사로로 보완했으며 아래 자동 시험 결과를 참조한다. 안내 표식은 정리·저장 완료했다. 카트 탑승/하차·축 구동과 고리 연결은 팀 메서드 기반 검사이며 실제 키보드 전체 경로 통과를 보장하지 않는다. 구·세모 실제 F 연결/해제와 휠 양방향 길이 변경은 확인했다. 지속 입력 스윙, 고리 간 연속 이동·최종 착지, 전체 실제 조작 완주는 미검증이다.

CP07에서 팀 카메라가 벽·덕트 뒤로 가려지는 화면을 확인했다. 구조물에 따라 카메라 위치·거리를 조절하는 방향은 담당자 검토 사항이며 현재 적용하지 않았다. 일반 이동과 스윙의 입력 방향 계산 기준도 달라 담당자 확인 대상으로 남겼다. 팀 코드는 담당자가 수정하며 이 맵에 자체 대체 카메라나 물리 보조를 추가하지 않는다.

검증 도구 및 로그는 프로젝트 외부 작업 폴더에 보관한다. 팀 코드·프로젝트 설정 변경 없이 이 폴더의 후보 변경만 검토한다. develop 직접 업로드/병합은 금지한다.

## 경사로 보완 — 2026-09-15 10:40 재검증

수직 계단면을 경사로와 쉼터로 교체했다. 목적지 높이9.6을 유지하며 경사 끝은 쉼터보다0.35 높게 연결했다. 조리대 출구 발판은 x39.2~44.8,z70.5~76이다. 팀 플레이어·물리 설정은 그대로다.

최신 자동 시험(ramp_resume_r10)은 세 도형×두 경로의 무점프 압력 이동6건과 도착 후 정지6건, 총12건 통과했다. 합성 수평 속도 기반 물리 시험이며 키보드 전체 완주 검증은 아니다. 이 결과는 앞선 계단 실패 및 발판 확대 미검증 상태를 갱신한다. 전체 맵·입력·카메라 검증 및 업로드 승인은 별도다.
