# 맵4 실험실

Unity `2022.3.62f3`에서 `Assets/LaboratoryMap4/Scenes/Map4_Master.unity`를 열고 Play를 누릅니다. Master가 CH1부터 CH8까지의 섹터 씬을 불러옵니다.

- WASD 또는 방향키로 이동하고 마우스로 시점을 돌립니다.
- Space로 점프, Tab으로 도형 전환, E로 상호작용, R로 체크포인트 복귀를 합니다.
- CH2에서 구출에 성공하면 첫 도형이 문을 통과할 때 세 도형이 CH4로 이동합니다. 시간 초과 시 CH3으로 이어집니다.
- CH5에서 경고가 보이면 도끼가 내려와 진자 운동을 시작합니다. CH6 바닥 포탈은 중앙에서 이동을 멈춰 들어갑니다.
- CH8에서 관리자를 재우고 열쇠로 문을 열면, 첫 도형이 문을 통과할 때 세 도형이 모이며 완료됩니다.

`Tools > Laboratory Map4 > Batch > 3. Build Windows EXE`로 맵4 전용 실행 파일을 만들 수 있습니다.

실제 키보드 연속 완주와 CH5·CH8 체감 난도 검증이 남아 있습니다.
