# 맵2 · 연구원 식당 주방

Unity 6000.3.24f1에서 메인 메뉴의 **싱글플레이 → 맵 2**를 선택하거나, 멀티플레이 방에서 시작 맵을 **맵 2**로 설정한다. 에디터에서 직접 열 씬은 [Map2KitchenTeamTrial.unity](Map2KitchenTeamTrial.unity)다.

세척기부터 배출구까지 일곱 구역의 동선, 실패 시 복귀 위치, 싱글과 협동 조작은 [맵2 섹터별 기믹 목록](../../docs/level-design/맵2_섹터별_기믹_목록.md)에서 확인할 수 있다.

싱글에서는 **Tab**으로 도형을 바꾸고 집결 표시에서 **E**로 뒤처진 도형을 부른다. 협동 다리는 입구 발판을 밟아 펼친 뒤 다른 도형이 맞은편 발판에 닿으면 고정된다.
