## 브랜치 전략
- `main` : 릴리즈 전용
- `develop` : 개발 통합
- `feature/*` : 기능 단위 작업

## 시작하기
1. `develop` 브랜치 클론
2. Unity Hub에서 프로젝트 열기
3. 작업 전 반드시 `feature/` 브랜치 생성
