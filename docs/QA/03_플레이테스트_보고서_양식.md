## 4. 세션 진행 절차

1. 참가자에게 테스트 목적이 아닌 기본 조작과 녹화 사실만 안내합니다.
2. 진행자는 플레이 중 정답이나 이동 방향을 먼저 알려주지 않습니다.
3. 참가자가 3분 이상 진행하지 못할 때만 정해진 단계에 따라 힌트를 제공합니다.
4. 발화, 망설임, 반복 행동, 실패 지점과 도움 요청 시각을 기록합니다.
5. 종료 후 기억에 의존하지 않도록 즉시 인터뷰를 진행합니다.
