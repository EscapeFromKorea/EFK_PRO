# 문서화 정책

> 2026-08-11 회의 상정 — 문서화 체계 개편 제안(김민섭) 기반

## 원칙

1. **MD가 원본(source of truth)이다.** `docs/` 아래 마크다운 파일이 최신 방향성의 기준이다.
2. **코드 변경과 같은 PR에서 문서도 같이 리뷰받는다.** 기능/로직을 바꾸는 PR은 관련 문서를 같은 PR에 포함시킨다. 문서만 바뀌는 PR도 가능하다.
3. **main(로컬 기준 `local_test`) 병합 후 필요 시 아티팩트로 publish**해서 팀원이 항상 같은 최신본을 링크로 확인한다.
4. **Notion은 마일스톤 단위 스냅샷 아카이브 역할만 한다.** 실시간 동기화 대상이 아니며, 비개발 인원 공유용이다.
5. **PR은 [pr-template.md](pr-template.md) 형식을 따른다.** 변경 사항마다 전/후 코드, 채택/기각 대안, 테스트 방법, 5줄 요약을 남겨서 리뷰어가 본문을 안 읽어도 전체 그림을 잡을 수 있게 한다.

## 폴더 구조

```
docs/
├── gameplay/       # 게임플레이 시스템 (싱글+스왑 프로토타입, DreamThreadSystem 등)
├── level-design/   # 맵/퍼즐 설계 규칙
├── art-pipeline/   # 에셋 네이밍, 아트 파이프라인
├── systems/         # 세이브/로드 등 엔진 시스템
├── conventions/     # 이 문서 포함, 브랜치/리뷰 등 팀 컨벤션
└── PRD/             # 기존 맵별 PRD 문서 (기존 유지, 이번 개편 범위 아님)
```

## 적용 범위 (2026-08-11 기준)

이번 커밋은 폴더 구조와 이 정책 문서만 반영한다. 각 도메인 폴더의 실제 콘텐츠는 팀원이 필요할 때 채워 넣는다. 기존 `docs/PRD/*.md`는 이번 개편 대상이 아니며 그대로 유지한다.
