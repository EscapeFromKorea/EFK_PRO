# 맵 2 제작 필요 에셋

## 콘셉트

식당 주방의 접시 반납·세척 구역을 배경으로 한다. 플레이어는 접시를 운반하는 컨베이어 벨트 위에서 쥐, 바퀴벌레, 물줄기 등을 피하며 이동한다.

## 필수 에셋

현재 구상된 플레이에 직접 필요한 모델이다. 제작 전에 기존 맵의 에셋을 재사용하거나 개선할 수 있는지 확인한다.

| 에셋 | 플레이 역할 | 블렌더 제작 참고 사항 |
| --- | --- | --- |
| 쥐 | 벨트 주변에서 이동하거나 플레이어를 추격하는 장애물 | 몸통, 다리, 꼬리가 구분되는 형태로 제작하고 대기·이동·방향 전환 애니메이션을 고려한다. |
| 바퀴벌레 | 벨트 위나 틈에서 등장해 이동을 방해하는 장애물 | 더듬이와 다리가 보이도록 제작하고 대기·이동 애니메이션을 고려한다. |
| 컨베이어 벨트 구간 | 플레이어가 이동하고 장애물을 피하는 주 경로 | 기존 벨트 에셋의 재사용을 우선 확인한다. 신규 제작 시 직선·회전 구간의 연결과 충돌 범위를 확인한다. |
| 세척 장치와 물 분사구 | 물줄기 장애물의 위치와 작동 방향을 보여주는 구조물 | 기존 세척 장치의 재사용을 우선 확인한다. 물줄기의 실제 판정과 효과는 Unity에서 연결한다. |

## 추가 제안

아래 에셋은 필수 플레이 구성에 포함하지 않는 선택 사항이다. 주방의 분위기를 더하거나 이후 장애물·발판 아이디어를 확장할 때 활용할 수 있다.

- **컵·유리잔:** 벨트 위에 놓이거나 굴러가는 소품.
- **숟가락·포크·젓가락과 수저통:** 반납 구역을 꾸미거나 향후 장애물로 활용할 소품.
- **음식물 찌꺼기:** 양배추 잎, 면발, 빵 조각, 생선 가시 등 해충 주변을 꾸미는 소품.
- **식판과 설거지 바구니:** 주방 소품 또는 향후 발판 후보. 식판은 기존 맵의 에셋을 먼저 확인한다.
- **세척용 솔과 스펀지:** 세척 구역 소품 또는 향후 움직이는 장애물·발판 후보.
- **냄비·프라이팬:** 벨트 주변을 꾸미거나 향후 발판으로 활용할 소품.
- **배경 소품:** 접시 선반, 건조대, 세제통, 고무장갑, 행주, 배수구, 주문서와 클립보드.

## 제작 시 확인할 사항

- 플레이어 시점에서 에셋의 형태와 이동 경로가 잘 보이는지 확인한다.
- 움직이는 몸체나 부품은 애니메이션 또는 Unity에서 제어하기 편하도록 분리 여부를 정한다.
- 발판과 장애물은 시각 모델과 충돌 범위를 함께 확인한다.
- 최종 크기, 모델 스타일, 애니메이션 범위와 실제 게임 기능은 구현 전에 결정한다.
