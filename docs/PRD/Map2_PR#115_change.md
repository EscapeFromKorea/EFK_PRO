# [FIX] 수직 기류 지속 및 시소 하중 판정 오류 수정

## 개요 (Overview)

수직 기류가 램프 종료 후 끊기는 문제와 시소의 복수 콜라이더 하중 판정 오류를 수정합니다. 시소 자동 보정의 대상·적용 시점을 보완하고, 씬 물리 설정 보존 및 맵2 골 필요 인원 설정을 추가합니다.

- 관련 이슈: 별도 번호가 제공되지 않았습니다.

## 변경 사항 (Changes)

- 수직 기류 지속 적용
  - `PlayerWindReceiver`에서 수직 속도 하한·상한 계산을 조기 반환보다 먼저 수행합니다.
  - 토크 이동 모드에서 램프 종료 후 `delta`가 0이어도 필요한 수직 속도 보정을 계속 적용합니다.
  - 수평 바람의 차분 적용 방식과 바람보다 강한 방향의 점프·낙하 속도는 유지합니다.
- 시소 자동 보정 대상 및 적용 시점 보완
  - 기존 `Rigidbody`와 `HingeJoint`가 모두 있는 대상에만 보정기를 추가합니다.
  - `SeesawTuningNotes`가 있거나, 이름에 `seesaw`가 포함되고 `plateUseGravity`가 켜진 `RotatingPlate`를 대상으로 합니다.
  - `SceneManager.sceneLoaded`를 통해 추가 로드된 씬에 대응하고 중복 구독을 방지합니다.
  - 런타임 생성 대상은 `SeesawTuningNotes.Start` 또는 `RotatingPlate.Start`에서 동일한 검사를 수행하며, 보정기를 중복 추가하지 않습니다.
- 시소의 복수 콜라이더 접촉 유지
  - 개별 `OnCollisionExit`에서 Rigidbody 전체를 하중 목록에서 삭제하던 처리를 제거합니다.
  - 남은 콜라이더의 `OnCollisionStay`로 접촉 시각을 갱신하고, 갱신이 물리 스텝 간격의 1.5배를 초과해 끊긴 하중만 제거합니다.
- 시소의 씬 물리 설정 보존
  - `enforceResponsivePhysics`의 기본값을 `false`로 변경합니다.
  - 기본 상태에서 회전 저항·최대 각속도·힌지 제한을 강제로 덮어쓰지 않습니다.
- 맵2 골 인원 설정 및 Collider 캐시
  - `requiredPlayerCount`를 노출하고 기본 3명, 최소 1명으로 판정합니다.
  - Collider를 `Awake`에서 캐시하고 Update마다 Bounds를 한 번 읽습니다.
  - 파괴·비활성화되었거나 골 영역을 벗어난 플레이어를 도착 인원에서 제외합니다.
  - 완료 로그에 설정된 목표 인원을 표시합니다.

## 테스트 방법 (How to Test)

1. **수직 기류 지속:** 일반 이동·토크 이동 각각에서 상승·하강 WindZone에 진입합니다. 즉시 적용과 램프 적용을 모두 시험하고, 목표 세기에 도달한 후에도 기류가 유지되는지 확인합니다. 상승 기류에서 이탈하면 수직 속도 강제 유지가 해제되는지도 확인합니다.
2. **시소 자동 보정:** 기존 Rigidbody·HingeJoint가 없는 대상에는 물리 컴포넌트나 보정기가 추가되지 않는지 확인합니다. 적격 시소에는 보정기가 하나만 붙고, 이름만 같은 일반 회전판은 제외되는지 확인합니다.
3. **시소 하중·설정:** 복수 콜라이더를 가진 물체를 판에 올리고 한 콜라이더만 이탈시킵니다. 남은 접촉의 하중이 유지되는지 확인합니다. `enforceResponsivePhysics = false`에서 미리 지정한 회전 저항과 힌지 제한도 유지되는지 확인합니다.
4. **골 인원:** 기본 3인 설정에서 한 명만 도착하면 완료되지 않는지 확인합니다. `requiredPlayerCount = 1`로 설정한 솔로 테스트에서는 한 명의 도착으로 완료되는지 확인합니다.
5. **추가 수동 확인:** 씬을 추가 로드하거나 적격 시소를 런타임에 생성해 보정기 연결을 확인합니다. 실제 맵에서 시소의 기울기·발사 강도·쐐기 고정과 전체 완주도 확인합니다. 이 단계는 아직 검증하지 않았습니다.

**예상 결과:**

기류가 램프 종료 후에도 유지되고, 시소의 남은 접촉 하중과 기존 물리 설정이 보존되어야 합니다. 적격 시소에만 보정기가 중복 없이 적용되며, 골은 설정한 인원이 도착해야 완료되어야 합니다.

## 리뷰 포인트 (Review Focus)

- 수직 바람 보정이 `delta = 0`인 상태에서도 실행되고, 기류 이탈 후에는 강제 유지가 해제되는지 확인 부탁드립니다.
- 시소 보정 대상의 물리 컴포넌트·마커·중력 설정 검사와 추가 씬 로드·런타임 생성 시점의 처리를 확인 부탁드립니다.
- 복수 콜라이더의 일부 접촉 종료 시 하중이 사라지지 않는지 확인 부탁드립니다.
- 기존 씬·프리팹에 `enforceResponsivePhysics = true`로 저장된 값은 기본값 변경만으로 해제되지 않습니다.
- 시소 추가 토크 계수 `24`는 기존 기울기 보정 의도를 유지한 값입니다. 실제 맵에서 움직임이 과도한지는 플레이 확인이 필요합니다.

## 추가 메모 (Additional Notes)

Unity 2022.3.62f3 임시 프로젝트에서 컴파일과 플레이 모드 회귀 검사 21건을 통과했습니다.

| 검사 | 건수 | 결과 |
|---|---:|---|
| 일반·토크 이동 × 즉시·램프 적용 × 상승·하강 기류 지속 | 8 | 통과 |
| 상승 기류 이탈 후 수직 속도 강제 유지 해제 | 4 | 통과 |
| 시소 물리 컴포넌트 검사·중복 방지·설정 보존·이름 단독 제외·적격 회전판 보정 | 5 | 통과 |
| 복수 콜라이더 하중 등록과 한 콜라이더 이탈 후 접촉 유지 | 2 | 통과 |
| 기본 3인 골의 조기 완료 방지와 명시적 1인 골 완료 | 2 | 통과 |

시소 추가 토크는 PhysX 접촉 하중에 더하는 의도적인 보정이며, 무게를 제곱하는 계산은 아닙니다. `loadTorqueMultiplier = 0`으로 추가 토크를 끌 수 있습니다. `RotatingPlate` 자체에도 Rigidbody·HingeJoint 필수 선언이 있으나 자동 보정 경로에도 명시적인 존재 검사를 추가했습니다.

골은 기본 3인 완주 규칙을 유지합니다. 리스폰이나 일시적인 비활성화로 현재 인원이 줄었다고 목표 인원을 자동 축소하지 않으며, 솔로 테스트는 필요 인원을 명시적으로 설정합니다.

위 검사에는 실제 추가 씬 로드·지연 생성의 전체 생명주기 검증과 실제 맵의 시소 강도·쐐기 고정·키보드 전체 완주는 포함되지 않습니다.
