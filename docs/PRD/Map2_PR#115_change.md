# [FIX] 맵2 기믹 안정화 및 숟가락 투석기·동선 보완

## 개요 (Overview)

바람·시소의 동작 오류를 수정하고, 투석기를 주방에 어울리는 거대 숟가락으로 교체했습니다. 섹터 건너뛰기를 막기 위한 벽과 이동 지형도 보완했습니다.

## 관련 이슈 (Related Issues)

- 관련 PR: #115
- 반영 범위: `5dcd13b`의 기믹 수정부터 `4fbfa04`의 차단 벽 배치까지

## 변경 사항 (Changes)

- **바람:** 토크 이동 모드에서도 상승·하강 기류가 램프 종료 후 계속 적용되도록 수정했습니다.
- **시소:** 복수 콜라이더의 일부 접촉이 끊겨도 하중을 유지합니다. 자동 보정 대상 검사와 추가 씬·런타임 생성 대응을 보완하고, 물리값 강제 보정은 기본으로 껐습니다.
- **골:** 기본 3인 완주를 유지하면서 테스트용 필요 인원을 설정할 수 있게 했고, Collider를 캐시했습니다.
- **투석기:** 조향·장전·탑승·발사 기능을 유지한 채 숟가락 외형으로 교체했습니다. 바퀴 외형·충돌을 제거하고, 움직이는 고무줄과 재사용 프리팹·적용 도구를 추가했습니다.
- **동선:** 차단 구조물 3개를 추가하고 기존 난간·상부장·상자·착지대의 위치와 크기를 조정했습니다.

## 테스트 방법 (How to Test)

대상 씬: `Assets/Scenes/Map2_Kitchen/Scenes/Map2_Kitchen.unity`

1. 상승·하강 기류 안에서 바람이 계속 유지되고, 이탈하면 강제 유지가 해제되는지 확인합니다.
2. 시소에 복수 콜라이더 물체를 올려 일부 접촉이 끊겨도 하중이 유지되는지 확인합니다.
3. 골을 기본 3명과 테스트용 1명으로 설정해 각각 완료 조건을 확인합니다.
4. 구의 `C` 조향, 정사면체의 `C`·휠 장전, 정육면체의 탑승·발사를 거쳐 벽 파괴까지 진행합니다.
5. 천장·덕트에서 후반 섹터로 점프·낙하·스윙을 시도하고, 차단 벽이 정상 경로와 카메라를 방해하지 않는지도 확인합니다.

**예상 결과:** 기믹이 안정적으로 동작하고, 기존 협동 조작을 유지하면서 정상 순서로 맵을 진행할 수 있어야 합니다.

## 리뷰 포인트 (Review Focus)

- 시소 추가 토크 계수 `24`는 유지했습니다. 실제 맵에서 과도하게 기울거나 튀지 않는지 확인이 필요합니다.
- 이미 저장된 `enforceResponsivePhysics = true`는 자동으로 꺼지지 않습니다.
- 차단 벽은 배치 방식의 보완입니다. 벽 위·옆 우회와 체크포인트·`R`을 통한 건너뛰기는 별도 확인이 필요합니다.
