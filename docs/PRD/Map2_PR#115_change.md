## 2. 반영한 변경

### 2.1 수직 기류 지속 적용

`useTorqueRolling`을 사용하는 플레이어는 바람 램프가 끝나면 이전 프레임 대비 변화량인 `delta`가 0이 됩니다. 기존 코드는 이때 조기 반환하여, 중력으로 감소한 수직 속도를 다시 보정하지 못했습니다.

- 수직 속도 하한·상한 계산을 조기 반환보다 먼저 수행합니다.
- `delta`가 작아도 수직 속도를 수정해야 하면 속도를 적용합니다.
- 수평 바람의 기존 차분 적용 방식은 유지합니다.
- 상승 바람은 목표 수직 속도 이상, 하강 바람은 목표 수직 속도 이하를 유지합니다. 이미 더 강한 방향의 점프·낙하 속도는 보존합니다.

### 2.2 시소 자동 보정 대상과 적용 시점

- 자동 보정 전 대상에 기존 `Rigidbody`와 `HingeJoint`가 모두 있는지 확인합니다. 둘 중 하나라도 없으면 보정기를 추가하지 않습니다.
- `SeesawTuningNotes`가 있는 오브젝트를 시소로 인식합니다.
- `RotatingPlate`는 이름에 `seesaw`가 포함되고 `plateUseGravity`가 켜져 있어야 자동 보정 대상이 됩니다.
- `SceneManager.sceneLoaded`에 연결하여 추가 로드된 씬에도 적용합니다. 이벤트 중복 구독을 방지합니다.
- 런타임에 생성되는 대상은 `SeesawTuningNotes.Start` 또는 `RotatingPlate.Start`에서 같은 검사 함수를 호출합니다.
- 이미 `SeesawWeightTilt`가 있으면 중복 추가하지 않습니다.

리뷰 보충: 현재 `RotatingPlate` 자체에도 Rigidbody·HingeJoint 필수 컴포넌트 선언이 있어 일반적인 생성 과정에서 두 컴포넌트가 없는 상태는 발생하기 어렵습니다. 자동 보정 경로에도 명시적인 존재 검사를 추가했습니다.

### 2.3 시소의 복수 콜라이더 접촉 유지

기존 `OnCollisionExit`은 콜라이더 한 쌍의 접촉이 끝나도 해당 Rigidbody 전체를 하중 목록에서 삭제했습니다.

- 개별 Exit에서 Rigidbody를 즉시 삭제하는 처리를 제거했습니다.
- 남은 콜라이더의 `OnCollisionStay`가 접촉 시각을 갱신합니다.
- 접촉 갱신이 물리 스텝 간격의 1.5배를 초과하여 끊긴 하중은 기존 시간 검사로 제거합니다.

### 2.4 시소의 씬 물리 설정 보존

- `enforceResponsivePhysics`의 기본값을 `false`로 변경했습니다.
- 기본 상태에서는 `angularDrag`, 최대 각속도, 힌지 제한을 강제로 변경하지 않습니다.
- 인스펙터에서 해당 옵션을 직접 켜면 기존 물리 보정을 사용합니다.
- 이미 씬·프리팹에 `true`로 저장된 값은 기본값 변경만으로 자동 해제되지 않습니다.

### 2.5 맵2 골 인원 설정과 Collider 캐시

- `requiredPlayerCount`를 인스펙터에 노출했습니다. 기본은 3명이며 솔로 테스트 시 1명으로 설정할 수 있습니다. 판정 시 최소 1명으로 제한합니다.
- 골 Collider를 `Awake`에서 캐시하고, 매 Update에서는 Bounds를 한 번 읽어 사용합니다.
- 파괴·비활성화되었거나 골 영역을 벗어난 플레이어는 도착 인원에서 제외합니다.
- 완료 로그에 설정된 목표 인원을 표시합니다.

## 3. 검토 후 유지한 내용

### 시소 추가 토크 계수 24

한쪽 하중으로 시소가 충분히 기울도록 하는 기존 요청에 따른 보정이므로 유지했습니다. PhysX 접촉 하중에 추가 토크가 더해지는 구조이며, 무게를 제곱하여 적용하는 계산은 아닙니다. 툴팁에 추가 토크임을 명시했습니다. `loadTorqueMultiplier`를 0으로 설정하면 추가 토크를 끌 수 있습니다.

실제 맵에서 과도한 움직임이 발생하는지는 이번 검사로 확인하지 않았으므로 계수를 임의로 낮추지 않았습니다.

### 기본 3인 완주 조건

리스폰이나 일시적인 비활성화로 플레이어 수가 줄었다는 이유로 목표 인원을 자동 축소하지 않습니다. 기본 3인 완주 규칙을 유지하고, 솔로 테스트는 필요 인원을 명시적으로 설정하는 방식으로 지원합니다.
