# 격리실 협력 구출 장치 (Isolation Rescue) — PRD

> 독립 신규 기믹. 실험실 CH2 전용. 출처: Notion "요구사항명세서" —
> `[실험실 CH2] 격리실 협력 구출 장치`.
> 상태: **기획 단계 — PRD 작성만 완료, 구현 전.**
> 스코프 메모: `docs/PRD/RoleClueTerminal.md`(CH7·8 역할 슬롯 시스템)와는 **별도 구현**이다 —
> 이유는 해당 문서 §1 "CH2 스코프 제외(확정)" 참고. CH2의 "안쪽/바깥쪽"은 위치를 골라 선택하는
> 역할이 아니라 진입 이벤트로 자동 결정된다.

## 1. 기획 의도 / 목적

안쪽과 바깥쪽에 **서로 다른 단서**를 나눠 줘서, 게임 내 텍스트/음성 채팅 없이 참가자가 실제
대화로 정보를 교환해야 풀리게 만드는 협동 퍼즐이다. 안쪽 플레이어는 기호 순서(예: 달·파도·
십자)를 보고, 바깥 플레이어는 기호-레버 대응표를 보고 레버를 순서대로 조작한다.

- 시간 내 성공하면 **CH4 숏컷**을 사용할 수 있다. 시간 초과 시 **CH3 경로**로 합류한다(패널티가
  아니라 분기다 — 실패해도 진행은 계속된다).
- 재도전에서는 **정답 순서만 바뀌고 레버-기호 대응은 고정**된다. 즉 바깥 플레이어의 대응표
  지식은 재사용 가능하지만, 매번 안쪽에서 새로 전달받아야 한다.
- 격리 제어·단서 표시·순서 판정·타이머는 이 문서가 새로 만들고, 레버·문·시간 처리·출구는
  기존 컴포넌트를 재사용한다. 방 자동 생성이나 게임 내 음성/채팅 기능은 범위 밖이다.
- **3단계 구성과 실제 기호/레버 데이터는 미확정 콘텐츠 구성안**이다 — 이 PRD는 그 예시를
  그대로 유지하되 "확정 규칙"과 "미결정 콘텐츠"를 구분해서 표기한다(§4).

## 2. 동작 시나리오

1. 수색 레버로 관찰문이 열린 뒤, **첫 번째로 격리 진입점을 완전히 통과한 참가자**가 격리
   후보가 된다. 문 안전검사(참가자/상자가 문에 끼지 않았는지)를 통과해야 격리가 확정된다.
2. 격리 후보가 준비 중 되돌아 나오면 취소된다. 여러 명이 동시에 진입해도 판정 순서상 첫 유효
   참가자만 선정되고, 나머지는 바깥에 남는다 — 두 명이 함께 갇히는 연출은 금지.
3. 안쪽/바깥쪽 양쪽이 각자 준비 확인(`READY_IN`/`READY_OUT`)을 누르면 1단계 단서가 표시되고
   타이머가 시작된다.
4. 안쪽 플레이어가 순서판의 기호를 말로 전달하면, 바깥 플레이어가 대응표를 읽고 레버를 그
   순서대로 조작한다. 3개를 모두 맞히면 그 단계가 완료되고 다음 방의 문이 열린다.
5. 오답이면 현재 단계에서 입력한 답만 지워지고 정답 순서가 왼쪽으로 한 칸 순환한다(레버
   위치는 그대로, 순서만 바뀜). 완료된 이전 단계와 남은 시간은 유지된다.
6. 마지막 단계까지 성공하면 바깥 전원이 켜진 상태에서 안쪽 해제 버튼을 눌러 구출을 완료한다.
7. 제한시간 안에 성공 → CH4 숏컷 권한 부여. 시간 초과 → 입력 잠금, 비상문 개방, 격리 해제
   후 CH3 경로로 합류(숏컷 없음).
8. 개인 추락은 자기 역할(안쪽/바깥쪽)의 안전점으로 복귀한다 — 단계·입력·남은 시간은 그대로
   유지된다. 이 복귀는 `docs/PRD/SectionRespawn.md`가 정의하는 "지정 목적지로의 개인 복귀"
   경로를 그대로 재사용한다(`C2_IN_SAFE`/`C2_OUT_SAFE`가 각각 `SectionSafePoint` 인스턴스가
   된다).

## 3. 컴포넌트 / 스크립트 설계

저장소 공통 발신자-수신자 패턴을 따른다. 예상 폴더: `Assets/IsolationRescueSystem/`.

- **`IsolationCaptureTrigger`** (`C2_CAPTURE`) — 진입점 트리거. 여러 참가자가 동시에 닿아도
  판정 순서상 첫 유효 참가자만 확정하고 나머지는 통과시키지 않는다(격리 안 됨). 문 안전검사
  완료 신호를 받아야 최종 확정.
- **`IsolationRescueController`** (챕터당 1개, 상태 보유자) — §4 상태표(대기/준비/진행/최종
  해제 대기/성공/시간 초과/중단)를 그대로 구현. 현재 단계 인덱스, 문제 버전, 입력 목록,
  시도 번호(전체 재시작마다 증가)를 갖는다.
- **`ClueBoard`** (`C2_CLUE_1~3`) — 안쪽에서만 보이는 순서판. 컨트롤러의 현재 단계 데이터를
  구독해 표시만 한다(판정 로직 없음).
- **`CorrespondenceMap`** (`C2_MAP`) — 바깥에서만 보이는 대응표. 고정 데이터(기호→레버 번호)를
  표시.
- **`SequenceLever`** (`C2_LEVER_1~3`, 기존 `DoorSystem` 레버 컴포넌트 재사용/확장) — 선택 시
  1회 신호만 컨트롤러에 전달한다(상태 유지 중 반복 신호를 여러 번으로 세지 않는다).
- **`SequenceJudge`** (컨트롤러 내부 로직 또는 별도 컴포넌트) — 레버 입력을 현재 정답 순서와
  비교. 정답이면 입력 목록에 추가하고 진행도(예: 1/3)만 바깥에 노출, 오답이면 입력을 지우고
  순서를 왼쪽으로 1칸 순환.
- **`IsolationDoor`/`EmergencyDoor`** (`C2_PASS_1~2`, `C2_EMERGENCY`, 기존 `DoorSystem` 재사용) —
  단계 성공 시 대응 문을 영구 개방(다시 닫지 않음). 비상문은 모든 내부 공간에서 접근 가능하며
  타이머 만료 또는 취소 시에만 개방.
- **`PowerHoldSwitch`** (`C2_POWER`) — 외부 유지 스위치. 최종 해제의 전제 조건 중 하나.
- **`ReleaseButton`** (`C2_RELEASE`) — 내부 최종 해제 버튼. 외부 스위치 ON + 마감 전 조건에서만
  유효.
- **`IsolationTimer`** (`C2_TIMER`) — 제한시간 T(양수 필수). 타이머 없는 격리 시작은 거부한다.
- **재사용, 신규 코드 없음**: 출구 목표(`C2_EXIT3`/`C2_EXIT4`)는 기존 출구 시스템, 개인 추락
  복귀는 `docs/PRD/SectionRespawn.md`가 정의하는 지정 목적지 복귀(본문 §2의 8번 항목 참고),
  문/레버 기반 동작은 기존 `DoorSystem`.

## 4. 확정값 / 기본값

| 항목 | 확정 내용 |
|---|---|
| 격리 후보 선정 | 진입점을 완전히 통과한 **첫 유효 참가자 1명**만. 동시 진입 시에도 판정 순서상 하나만 선정 |
| 격리 취소 조건 | 문이 참가자/상자에 막혀 안전검사 실패 시 취소 → 대기 상태로 복귀 |
| 재도전 시 변경 범위 | **정답 순서만 왼쪽으로 1칸 순환**. 레버 위치·기호 대응은 절대 바뀌지 않는다 |
| 오답 처리 | 현재 단계 입력만 삭제, 완료된 이전 단계·문·타이머는 그대로 유지 |
| 성공 판정 단위 | 단계당 3개 입력 순서 일치 |
| 시간 내 성공 | CH4 숏컷 권한 부여, 타이머 정지 |
| 시간 초과 | 입력 잠금, 비상문 개방, 격리 해제, CH3 경로로 합류(숏컷 없음) — **패널티 없는 분기**로 취급 |
| 개인 추락 | 자기 역할(안쪽/바깥쪽) 안전점으로 복귀, 단계·입력·시간 보존 |
| 전체 재시작 | 모든 단계/문/준비 확인/권한 초기화, 새 시도 번호로 순서 재배정 |
| 최종 해제 조건 | 외부 스위치 ON **+** 내부 버튼 입력 **+** 마감 전. 동시에 누를 필요는 없음(순서 무관, 조건만 동시 충족) |
| 새 시스템 배제 | 방 자동 생성, 게임 내 음성/채팅 기능은 만들지 않는다 |

| 파라미터 | 타입 | 설명 | 상태 |
|---|---|---|---|
| 제한시간 T | `float`(초) | 격리 시작~마감까지. 양수 필수 | 미정(씬 튜닝 대상) |
| 3단계 구성/기호/레버 매핑 | 콘텐츠 데이터 | 원본 문서 예시(달=2/파도=1/십자=3, S1~S3) | **미확정 콘텐츠 구성안** |
| 비상 통로·준비 확인 세부 동선 | 레벨 데이터 | 방1→방2→방3 + 공통 비상 복도 | 세부 배치는 미정 |

**상태 전이표** (원본 문서 그대로):

| 상태 | 조건 | 결과 | 다음 |

| 진행 | 현재 단계 정답 완료 | 단계 고정·다음 문/단서 개방 | 진행 / 최종 해제 대기 |

| 종료 상태(성공/시간초과/중단) | 추가 입력 | 무시 | 유지 |

## 전체 재시작 처리

원본 문서가 명시한 표준 절차다(실험실 계열 문서 공통 5단계):

1. 새 입력·피해·예약된 동작을 중지한다.
2. 현재 시도를 종료해 이전 시도의 지연 입력을 무효화한다.
3. 대상자의 로프·탑승 등 이동 제어를 해제하고 안전한 시작 위치로 이동한다.
4. 이 챕터의 장치·문제·권한을 초기 상태로 복원한다. 다른 챕터의 진행은 보존한다.
5. 안전 복귀 완료를 확인한 후 준비 상태로 돌아간다. 개인 복귀는 본문에 지정한 항목만
   초기화한다.
