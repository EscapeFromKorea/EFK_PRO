# 규칙 배선 패널 (Wiring Panel) — PRD

> 독립 신규 기믹. 실험실 CH7에서 두 인스턴스(입구용/전력 유지용)로 재사용되는 범용 "연결
> 퍼즐" 컴포넌트. 출처: Notion "요구사항명세서" — `[실험실 CH7] 규칙 배선 패널`.
> 상태: **기획 단계 — PRD 작성만 완료, 구현 전.** `docs/PRD/ServerRoomPower.md`가 이 문서를
> 소비하는 CH7 전력 유지 장치를 정의한다.

## 1. 기획 의도 / 목적

규칙표에서 출력-입력 대응 관계를 찾아 선으로 연결하는 범용 퍼즐이다. **실제 전압 계산, 물리
케이블, 분기 회로는 구현하지 않는다** — 순수하게 "규칙표를 읽고 맞는 쌍을 고른다"는 인지
과제만 다룬다.

- **같은 프리팹, 다른 인스턴스**: CH7 입구(`W_ENTRY`)와 전력 유지(`W_POWER`)는 동일한
  컴포넌트를 각자의 회로 데이터로 배정받아 쓴다. 패널 자체는 "어디에 연결되는지" 모른다 —
  완료 시 신호만 발신하고, 그 신호를 문이 받을지 전력 장치가 받을지는 수신 측이 정한다
  (저장소 공통 발신자-수신자 분리 원칙).
- 입력 순서는 상관없다. 이미 연결된 출력을 다른 곳으로 바꾸려면 먼저 그 선을 해제해야 하고,
  오답 시도로 기존 정답 연결을 몰래 대체할 수 없다.

## 2. 동작 시나리오

1. 플레이어가 패널의 규칙표를 읽어 출력 A·B·C가 어느 입력 번호에 연결되는지 확인한다.
2. 출력 하나를 선택한 뒤 대응하는 입력 하나를 선택한다. 올바른 쌍이면 두 포트 사이에 선이
   남고, 출력 선택은 해제된다.
3. 틀린 쌍이면 새 선을 저장하지 않고 "대응표를 다시 확인하세요"를 표시한다. 이미 맞춘 선은
   그대로 유지되고 전력을 추가로 깎지 않는다.
4. 모든 쌍을 맞히면 완료가 잠기고 완료 신호가 1회 발신된다 — 입구 인스턴스는 문을 열고,
   전력 유지 인스턴스는 전력 회복을 요청한다.
5. 전력 유지용 인스턴스는 다음 회로를 배정받으면 선을 비우고 새 규칙표로 다시 시작한다.

## 3. 컴포넌트 / 스크립트 설계

예상 폴더: `Assets/WiringPanelSystem/`.

- **`WiringPanel`** (발신자, 프리팹 하나) — 포트 선택 상태, 연결된 선 목록, 정답 쌍 데이터,
  완료 여부를 갖는다. 완료 시 `UnityEvent`(또는 강타입 콜백)로 `{장치, 시도, 배정번호, 회로ID}`를
  발신한다. 입구 문이든 전력 유지 장치든, 수신자는 인스펙터에서 이 이벤트에 연결한다.
- **`WiringPort`** (`OUT_A/B/C`, `IN_1/2/3`) — 개별 포트 버튼. 출력 포트 선택 시 강조,
  입력 포트 선택 시 `WiringPanel`에 판정을 요청한다.
- **`WiringRuleDisplay`** (`W_RULE`) — 현재 회로의 규칙표를 표시(콘텐츠 데이터만 바인딩).
- **`WiringLineRenderer`** (`W_LINES`) — 연결된 쌍을 선으로 표시.
- **`W_CANCEL`** — 현재 출력 선택 취소 버튼.
- 회로 데이터는 `WiringCircuitData`(ScriptableObject 또는 인스펙터 직렬화 클래스)로 정의:
  회로 ID, 출력/입력 목록, 정답 쌍, 배정 번호. 필수 필드가 비어 있거나 중복 정답/존재하지
  않는 포트를 참조하면 **시작을 거부**한다(콘텐츠 오류를 런타임에 잡는다).

## 4. 확정값 / 기본값

| 항목 | 확정 내용 |
|---|---|
| 입력 순서 | 상관없음 — 어느 쌍부터 맞혀도 된다 |
| 출력 재연결 | 이미 연결된 출력을 다른 입력으로 바꾸려면 먼저 기존 선을 해제해야 한다 |
| 오답 처리 | 새 선 저장 안 함, 출력 선택만 해제, 기존 정답 선은 유지, 전력 추가 차감 없음 |
| 완료 후 잠금 | 입구 완료 후 잠금 유지. 유지 패널은 다음 배정 전까지 잠금, 다음 배정 시 연결 0/선택 0/배정번호 변경으로 리셋 |
| 완료 신호 형식 | `{장치, 시도, 배정번호, 회로ID}` — 문/전력 수신자는 이 신호를 **중복 처리하지 않는다**(같은 신호 재전달 시 무시) |
| 개인 복귀/패널 닫기 영향 | 미완성 출력 선택만 취소, 저장된 선은 유지 |
| 동시 요청 처리 | 공통 권한자가 순서대로 처리. 한 포트를 두 선이 동시에 점유할 수 없다 |
| 콘텐츠 검증 | 회로ID·출력/입력 목록·정답 쌍·배정번호 누락, 포트 중복 정답, 존재하지 않는 포트, 빈 정답은 시작 거부 |
| 조작 방식 | 실제 입력 키는 기존 팀 바인딩 사용 |

| 파라미터 | 타입 | 설명 | 상태 |
|---|---|---|---|
| 회로 데이터(ENTRY/POWER_1~3) | 콘텐츠 데이터 | 아래 "CH7 회로 데이터" 표 | **미확정 콘텐츠 구성안**(기본 난도 예시) |
| 조작 방식(드래그 vs 버튼 클릭) | UI 설계 | 원본은 "출력 선택 후 입력 선택" 버튼 조작안을 제시, 드래그/물리 플러그는 필수 아님 | 미결정(버튼 조작안이 기본 가정) |

## 6. 완료 조건 대비 검증

| ID | 준비/입력 | 기대 |
|---|---|---|
| W-01 | ENTRY에서 C→1, A→2, B→3 순서로 연결 | 입력 순서와 무관하게 완료 1회 |
| W-02 | A→2 연결 후 B→1 시도 | A선 유지, B선 생성 안 됨, 추가 전력 차감 없음 |
| W-03 | A→2 연결 후 B→2 시도(입력 포트 중복 점유) | A선 유지, "사용 중" 안내만 표시 |
| W-04 | 미완료 A선 해제 후 재연결 | 삭제/복원 정상 동작 |
| W-05 | 완료 신호 재전달(중복 발신) | 문/전력 쪽 결과 추가 없음(멱등) |
| W-06 | 새 배정 후 옛 배정 완료 신호 전달 | 무효 처리 |
| W-07 | 중간에 패널 닫고 다시 열기 | 저장된 선은 유지, 선택 상태만 초기화 |

## CH7 회로 데이터 (미확정 콘텐츠 구성안)

| 회로ID | 화면 규칙표 | 정답 쌍 |
|---|---|---|
| ENTRY | A는 2번, B는 3번, C는 1번 단자에 연결 | A-2, B-3, C-1 |
| POWER_1 | 출력 라벨과 입력 번호가 A-1/B-2/C-3으로 대응 | A-1, B-2, C-3 |
| POWER_2 | 출력 라벨과 입력 번호가 A-3/B-1/C-2로 대응 | A-3, B-1, C-2 |
| POWER_3 | 출력 라벨과 입력 번호가 A-2/B-3/C-1로 대응 | A-2, B-3, C-1 |

무작위 연결 생성은 하지 않는다 — 이 4개 회로가 입구/유지 조작 검증을 위한 기본 난도 전부다.
