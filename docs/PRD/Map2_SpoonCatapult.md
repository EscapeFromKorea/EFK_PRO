# 맵2 거대 숟가락 투석기

## 적용 위치

- 씬: `Assets/Scenes/Map2_Kitchen/Scenes/Map2_Kitchen.unity`
- 교체 대상: 씬의 기존 `Catapult` 1대
- 재사용 프리팹: `Assets/Scenes/Map2_Kitchen/Art/SpoonCatapult/KitchenSpoonCatapult.prefab`
- 메시·재질: 같은 `Art/SpoonCatapult` 폴더

## 외형

직접 생성한 로우폴리 메시로 구성한 주방 도구 발사대입니다. 얕고 길쭉한 스테인리스 숟가락 머리는 기존 버킷 위치에, 얇은 손잡이는 기존 팔에 맞추었습니다. 도마 받침, 작은 고정 클립, 접은 행주, 붉은 실리콘 그립, 작은 조향 고리와 두 줄의 고무줄을 함께 구성했습니다.

바퀴처럼 보이던 양쪽 원형 캡·허브와 가로 밀대를 제거했습니다. 기존 `Catapult_Wheel`의 충돌체도 비활성화하여 보이지 않는 바퀴에 걸리지 않게 했습니다. 숟가락 손잡이의 오목한 윤곽은 삼각분할하여 겹치는 면의 깜빡임을 방지합니다.

숟가락은 원래 `CatapultArm.armPivot`을 따라 장전·발사 시 회전합니다. `KitchenSpoonBands`는 움직이는 당김 앵커와 고정 핀 사이의 고무줄을 시각적으로 갱신합니다. 고무줄에는 추가 물리 힘이나 입력 처리가 없습니다.

## 유지한 기능과 조작

- 구: 기존 조향 고리 가까이에서 `C`로 도킹하고 좌우 이동 입력으로 조향, 다시 `C`로 해제합니다.
- 정사면체: 기존 당김 앵커에서 `C`로 연결하고 마우스 휠로 장전합니다. 다시 `C`를 누르면 발사합니다.
- 정육면체: 충분히 장전한 뒤 기존 버킷 근처에서 `C`로 탑승합니다. 발사 스윙이 끝날 때 분리됩니다.
- 장전 각도, 탑승 조건, 발사 타이밍·속도·방향, 원래 스크립트 참조, Rigidbody 설정과 기존 Transform은 보존했습니다. Collider는 바퀴를 비활성화한 것 외에 기존 설정을 유지합니다.
- 기존 충돌체에 시각 외형을 맞췄습니다. 추가한 외형에는 Collider나 Rigidbody를 붙이지 않았습니다.

## 재적용 방법

맵에는 교체 결과가 저장되어 있으므로 생성 도구를 실행하지 않고 씬을 열어 확인할 수 있습니다.

다른 기존 투석기에 적용하려면 편집 모드에서 해당 투석기의 루트 또는 자식을 선택하고 `Tools > Kitchen Map2 > Apply Spoon Skin To Selected Catapult`를 실행한 뒤 씬을 저장합니다. 이 도구는 현재 맵의 표준 투석기 구조와 크기를 기준으로 하므로 다른 크기·변형 투석기는 별도 외형 조정이 필요합니다.

`KitchenSpoonCatapultBuilder.BuildMap2`는 지정된 맵2 씬을 열고 숟가락 외형과 프리팹을 다시 생성하는 배치용 진입점입니다. 기존 시각 전용 `KitchenSpoon_Stand`와 `KitchenSpoon_Utensil` 자식을 교체하므로, 이 두 자식에 수동으로 추가한 장식이 있다면 재생성 전에 보관해야 합니다.

## 검증

Unity 2022.3.62f3에서 생성·컴파일과 기존 기믹/물리 컴포넌트의 직렬화 값 및 Transform 보존 검사를 통과했습니다. 바퀴 충돌체 비활성화는 의도한 변경으로 보존 비교 전에 적용합니다. 반복 적용에서도 보존 검사를 통과했습니다.

재사용 프리팹의 플레이 모드 검사 14건이 통과했습니다. 숟가락/고무줄 참조, 추가 충돌체 없음, 미장전 탑승 거부, 구 도킹·해제, 정사면체 연결, 장전 각도·팔 추종·고무줄 추종, 정육면체 탑승, 발사 스윙·분리·기존 속도 유지, 발사 후 가시성을 확인했습니다. 정상 크기·최대 장전 시험의 초기 발사 속도는 기존 설정과 동일한 `(0, 13.79, -11.57)` m/s였습니다.

검사는 원래 기믹 메서드와 트리거를 호출한 자동 검사입니다. 실제 키보드 입력으로 벽 파괴 및 섹터 전체 완주를 수행한 검사는 아닙니다.
