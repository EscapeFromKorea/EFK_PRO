# [FIX] 맵 3 시소 두 개가 비었을 때 초기 경사로 복귀

## 개요 (Overview)

인형의 집에서 두 시소가 반대 방향으로 기울어진 채 멈추면 낮은 쪽에서 다시 올라탈 수 없었습니다. 이제 마지막 도형이 내려가면 시소가 씬에 배치된 초기 경사로 돌아와 다시 이용할 수 있습니다.

## 변경 사항 (Changes)

- `DYN_DollLivingBoard_Ramp`와 `DYN_DollAtticBoard_Ramp`에 빈 판 복귀 옵션을 켰습니다. 이 옵션은 기본적으로 꺼져 있습니다.
- 도형이 판 위에 있으면 기존 자유 회전을 유지합니다. 판이 비면 약 0.2초 뒤부터 힌지 축에 토크를 가해 초기 경사로 부드럽게 복귀합니다.
- 두 ToyWorld 씬과 씬 생성 도구에 같은 설정을 반영했습니다.

## 테스트 방법 (How to Test)

1. Unity `6000.3.24f1`에서 `Assets/Scenes/Map3_ToyWorld/Scenes/Map3_ToyWorld.unity`를 실행합니다.
2. 인형의 집 거실과 다락에서 각 시소를 시작 방향과 반대로 기울입니다.
3. 도형을 시소 위에 둔 상태에서 각도가 강제로 돌아가지 않는지 확인합니다.
4. 마지막 도형을 내리고 시소가 초기 경사로 돌아오는지, 낮은 쪽에서 다시 올라탈 수 있는지 확인합니다.

**예상 결과** — 도형이 올라선 동안에는 기존처럼 기울고, 모두 내려가면 처음 배치된 경사로 부드럽게 돌아옵니다.

## 리뷰 포인트 (Review Focus)

- 여러 도형이 올라선 상태에서는 마지막 도형이 내려간 뒤 복귀가 시작되는지 확인해 주세요.
- 멀티플레이에서는 참가자 화면에서도 서버에서 복귀한 각도가 자연스럽게 반영되는지 확인해 주세요.
