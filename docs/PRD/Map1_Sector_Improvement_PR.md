# [FEAT] DayDream 네 섹터의 도형 협동 동선 개선

## 개요 (Overview)

맵 1의 P05·P06·P07·P09에서 구·정육면체·정사면체가 각각 진행에 필요한 장치를 맡도록 구성했습니다. 세 도형이 각 구간의 출구에 모이면 체크포인트가 저장됩니다.

## 관련 이슈 (Related Issues)

- 연결된 이슈 번호는 확인되지 않았습니다.

## 변경 사항 (Changes)

- **P05 실 스윙 협곡** — 정육면체의 반복 디딤돌을 화물 운반대로 교체했습니다. 정육면체가 탑승하고, 구가 운반대를 보내며, 정사면체가 합류 램프를 엽니다.
- **P06 몽유의 벽** — 구의 전원 섬과 정육면체의 잠금 발판을 추가했습니다. 정사면체가 상단을 연결하면 나머지 두 도형이 리프트로 올라옵니다.
- **P07 잠든 거인 깨우기** — 중앙의 낮은 지름길을 비활성화했습니다. 정육면체를 닻으로 사용해 구가 먼저 건너고, 정사면체가 핀 벽 위 스위치를 작동하면 무지개 다리가 열립니다.
- **P09 역풍 터널** — 실다리를 역풍 통로, 바람 제단과 상승 기류로 교체했습니다. 정육면체가 측면 문을 열고, 구가 바람을 전환하면, 정사면체가 높은 제단에서 최종 문과 복귀로를 엽니다.
- **체크포인트** — 지정 장치 완료와 세 도형의 합류를 확인하고 저장합니다. 뒤쪽 체크포인트에서 앞선 협동 구간을 건너뛰어 저장하지 못하도록 연결했습니다.
- **외형** — `Assets/Models`의 잔디·돌·나무·구름 모델로 외형을 구성했습니다. 장치에는 글자 대신 플레이어 메시를 재사용한 평평한 도형 표시를 넣었습니다. 충돌용 FBX 메시를 숨기고 통로와 돌문의 겹치는 면을 정리했습니다.

## 테스트 방법 (How to Test)

Unity `6000.3.24f1`에서 `Assets/Scenes/Map1_DayDream/Map1_DayDream.unity`를 여세요. 세부 동선은 [맵 1 협동 구간 플레이 가이드](../gameplay/map1_coop_sectors.md)를 참고해 주세요.

1. P05에서 정육면체를 운반대에 태운 뒤 구로 출발시키고, 정사면체로 합류 램프를 엽니다.
2. P06에서 세 장치를 서로 다른 순서로 작동합니다. 구와 정육면체가 함께 타면 리프트가 출발하고, 먼저 도착한 정사면체와 합류할 수 있는지 확인합니다.
3. P07에서 구를 실로 건너보내고 정사면체로 핀 벽을 올라갑니다. 마지막 스위치 이후에 무지개 다리가 열리는지 확인합니다.
4. P09에서 역풍, 구의 가속 점프, 정사면체의 상승 기류 이동을 순서대로 확인합니다. 바람 제단에서 출구로 이어지는 복귀로와 최종 문의 개방을 확인합니다.
5. 각 구간에서 다른 도형이 스위치를 밟거나 두 도형만 출구에 도착했을 때 진행이 확정되지 않는지 확인합니다. 카메라를 돌리며 새 발판과 나무 통로 접합부도 살펴봅니다.

**예상 결과** — 각 도형이 맡은 장치를 작동시키면 다음 경로가 드러나고, 세 도형이 합류한 뒤 체크포인트가 저장됩니다. 작동한 타일의 도형 표시는 녹색으로 바뀝니다.

## 리뷰 포인트 (Review Focus)

- P05·P06 운반 중 낙하한 도형이 운반대를 다시 타고 일행과 합류할 수 있는지 확인해 주세요.
- P07의 핀 벽과 P09의 상승 기류가 실제 조작에서 잘 읽히고, 각 담당 도형이 의도한 경로를 이용할 수 있는지 확인해 주세요.
- 협동 장치 상태와 탑승 이동은 멀티플레이에서 별도 확인이 필요합니다.
