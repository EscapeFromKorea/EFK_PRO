# 낙석(무너져 내리는 꿈의 파편) — PRD

맵 1 DayDream. 사양 원문 `맵1_낙석_구현사양.md`, 공통 전제 `맵1_협동기믹_구현사양.md` §0,
구현 메모 `Assets/FallingRockSystem/CLAUDE.md`.

## 무엇을 위한 기믹인가

낙석은 장애물 그 자체가 목적이 아니다. **모래시계 슬로우 + 구의 빠른 이동속도를 결합한 타이밍
퍼즐의 절반**이다(사양 §2). 세모가 몽환의 모래시계를 쳐야 구가 통과할 수 있으므로,
"혼자서는 못 지나가는 구간"으로 협동을 강제하는 장치다.

**모래시계 없이는 성립하지 않는다.** 낙석만 배치하면 감속이 없어 통과 창이 열리지 않고,
반대로 모래시계만 있으면 슬로우를 쓸 이유가 없다. 둘은 항상 같이 배치한다.

## 파라미터는 계산으로 정했다

사양 §4는 전부 `[TBD]`였다. 제안값을 찍지 않고 §0 공통 전제(1 Unit = 1m, 구 이속 7 U/s·지름 1 U)와
`SlowZone` 기본값(중력 0.5배, 하강 상한 2 U/s)에서 유도했다. **유도 계산과 통과 창 검산은
`FallingRockSpawner` 클래스 주석에 식으로 남겨 두었다** — 값을 조정할 사람은 그 검산을 다시 하면
된다(여기에 수치를 복사해두면 코드와 갈라진다).

핵심 결론 하나만 옮긴다: **낙하만 늦추면 퍼즐이 거꾸로 된다.** 유량 보존 때문에 낙석의 시간당
도착 수는 감속과 무관하게 일정한데, 낙석 하나가 통로를 막고 있는 시간은 `1/속도`로 늘어난다
(0.18초 → 1.0초). 그래서 감속만 걸면 통로가 비는 시간이 오히려 줄어 통과가 불가능해진다.
사양 §2의 "느려진 타이밍"은 시간 자체가 느려지는 모델을 전제하지만 `SlowZone`은 멀티 동기화를
위해 개별 물리만 늦추기 때문에 생기는 차이다.

그래서 **감속 중에는 스폰 주기도 함께 늘린다**(`spawnIntervalWhileSlowed`). 상태별로 주기를 따로
두는 것이 이 퍼즐의 핵심이고, 값 하나로 두면 "감속 없이는 어렵다"와 "감속 중에는 통과된다"를
동시에 만족시킬 수 없다. 자세한 계산은 `Assets/FallingRockSystem/CLAUDE.md` 참고.
