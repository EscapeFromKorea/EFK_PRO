# 가상 시약 혼합 장치 (Reagent Mixing) — PRD

> 독립 신규 기믹. 실험실 CH8 전용. 출처: Notion "요구사항명세서" —
> `[실험실 CH8] 가상 시약 혼합 장치`.
> 상태: **기획 단계 — PRD 작성만 완료, 구현 전.** `docs/PRD/ManagerSurveillance.md`(CH8 관리자
> 감시·수면·열쇠)가 이 문서의 완성물을 소비한다 — 두 문서는 한 쌍으로 읽는다.

## 1. 기획 의도 / 목적

책의 조합 순서와 혼합대의 재료 표식을 참가자들이 **말로 연결**하게 만드는 협동 퍼즐이다.
버튼 기반 재료 선택/투입, 버퍼, 오조합 처리, 완성물 권한만 다루며 **물리 붓기·유체 시뮬레이션·
실제 약물 조제는 구현하지 않는다**(가상 재료, 실제 의약품과 무관).

- 책 표시는 `docs/PRD/RoleClueTerminal.md`의 `BookPanel`을 그대로 재사용한다 — 조합법
  텍스트만 CH8 전용 콘텐츠로 바꾼다.
- 관리자 감지·잡힘·수면·열쇠는 이 문서의 책임이 아니다. 완성물이 만들어진 뒤 "사용 요청"을
  보내는 것까지가 이 문서의 역할이고, 그 요청을 수락할지·수면을 확정할지는
  `ManagerSurveillance`가 판정한다.

## 2. 동작 시나리오

1. 책 담당은 조합법을 읽고, 혼합 담당은 혼합대에 있는 재료의 이름과 표식을 말해 준다.
2. 책 담당의 안내에 따라 혼합 담당이 재료를 선택한다. 선택은 강조만 하고 투입되지 않으며,
   다른 재료로 바꿀 수 있다. "투입" 버튼을 눌러야 한 번씩 실제로 들어간다.
3. 정답 재료와 일치하면 버퍼에 추가되고 진행칸에 표식이 표시된다. 틀리면 "조합이 맞지
   않습니다. 혼합물을 비웠습니다"를 표시하고 버퍼/선택을 모두 지운다 — 재료는 무제한
   재사용 가능하고 책 내용은 그대로 유지된다.
4. 세 번째 정답을 맞히면 완성 상태가 되어 병이 표시되고, **팀 공유 완성물 권한 1개**가
   생성된다. 이후 투입/비우기는 잠긴다. 완성만으로 관리자가 잠들지는 않는다.
5. 참가자가 관리자 사용 지점에 가면 "완성물을 사용해 관리자를 재우기"가 표시된다.
   상호작용하면 `ManagerSurveillance`로 사용 요청을 보낸다.
6. 수면 수락 시 완성물 권한이 소모되고 병 표시가 "사용 완료"로 바뀐다. 거부 시(예: 이미
   수면 중이거나 팀 실패가 확정된 경우) 권한은 보존되고 거부 이유가 표시된다.

## 3. 컴포넌트 / 스크립트 설계

예상 폴더: `Assets/ReagentMixingSystem/`.

- **`MixingStation`** (혼합대, 상태 보유자) — 재료 버튼 3개(`R_L`/`R_N`/`R_V`), 선택 표시,
  투입 버튼, 비우기 버튼, 진행칸 3개, 완성 병 시각물을 갖는다. 정답 순서는 화면에 노출하지
  않는다(콘텐츠 데이터는 판정에만 존재).
- **`TeamCompletionToken`** (팀 공유 완성물 권한) — 팀 전체가 들고 다니는 권한 1개.
  물리적 운반/분실 퍼즐을 추가하지 않는다 — 순수 카운터.
- **`ManagerUsePoint`** (`C8_USE`, 발신자) — 상호작용 시 `ManagerSurveillance`에 "사용 요청"
  이벤트를 발신한다. 완성물이 없으면 안내만 표시하고 요청 자체를 보내지 않는다.
- **책 표시**: `docs/PRD/RoleClueTerminal.md`의 `BookPanel` 재사용, CH8 전용 콘텐츠(§6)
  바인딩.
- **연결 방향**: `MixingStation`은 `ManagerSurveillance`를 참조하지 않는다 — `ManagerUsePoint`가
  요청을 발신하고, `ManagerSurveillance` 쪽 컨트롤러가 수락/거부를 판정해 돌려준다(콜백 또는
  이벤트 응답). 혼합 장치 폴더가 관리자 로직을 모르게 유지한다.

## 4. 확정값 / 기본값

| 항목 | 확정 내용 |
|---|---|
| 재료 선택/투입 | 선택은 강조만(미투입), 투입 버튼을 눌러야 버퍼에 반영 |
| 오조합 처리 | 버퍼/선택 전체 초기화, 책/레시피는 유지, 재료 재사용 무제한 |
| 완성 조건 | 정답 재료 3개를 순서대로 투입 |
| 완성 후 잠금 | 투입/비우기 버튼 비활성화(완료 뒤 비우기 거부) |
| 완성물 성격 | 팀 공유 권한 1개. 사용 가능한 참가자는 팀원 전체 |
| 개인 낙하/패널 닫기/역할 교체 영향 | 버퍼·완성물 유지, 미제출 선택만 삭제 |
| 관리자 잡힘 시 초기화 범위 | 관리자에게 한 명이라도 잡히면 **혼합 버퍼·완성 병·완성물 권한·선택 상태 전부** 초기화(CH8 팀 전체 재시작의 일부). 의심·추격 단계만으로는 초기화하지 않는다 |
| 새 결과물 사용 제한 | 완성물 생성만으로 관리자가 자동으로 잠들지 않는다 — 반드시 사용 지점에서 수락되어야 함 |
| 화면 정보 격리 | 혼합 화면엔 재료 색·모양·이름과 이미 투입한 목록만(정답 순서 감춤). 책 화면엔 혼합대 현재 선택 미노출 |
| 물리 시뮬레이션 배제 | 물리 붓기/유체/실제 약품 계산 없음(확정 — 원본 요구) |

| 파라미터 | 타입 | 설명 | 상태 |
|---|---|---|---|
| 레시피 ID/정답 재료/결과물 ID | 콘텐츠 데이터 | §6 참고(`S01`, `[R_L,R_N,R_V]`, `SEDATIVE_S01`) | **미확정 콘텐츠 구성안** |
| 사용 가능 관리자 | 참조 | `C8_MANAGER` | 미확정(콘텐츠) |

## 6. CH8 재료·책 콘텐츠 (미확정 구성안)

| 재료ID | 혼합대 표시 이름 | 색 | 표식 |
|---|---|---|---|
| R_L | 루멘 | 파랑 | 삼각형 |
| R_N | 노바 | 주황 | 원 |
| R_V | 베일 | 흰색 | 사각형 |

레시피ID=`S01`, 정답 순서=`[R_L, R_N, R_V]`, 결과물ID=`SEDATIVE_S01`.

책 본문("안정화 용액 S-01"): 1페이지는 파란 삼각형(R_L)을 첫 번째로 넣으라는 안내, 2페이지는
주황 원(R_N)이 두 번째·흰 사각형(R_V)이 마지막이며 순서가 틀리면 처음부터 다시 시작한다는
안내, 3페이지는 완성된 용액을 관리자 사용 지점에서 사용해야 하며 혼합 완료만으로는 작동하지
않고, 수면 후 열쇠를 회수해 출구로 이동해야 한다는 안내. 책 담당 화면에는 혼합대의 현재 선택을
공유하지 않는다 — 혼합 담당이 표식을 말하고 책 담당이 다음 순서를 전달하는 구조를 강제한다.

## 7. 완료 조건 대비 검증

| ID | 준비/행동 | 기대 |
|---|---|---|
| M-01 | L→N→V 각각 선택+투입 | 1/3→2/3→완성, 병 표시·완성물 권한 1개 생성 |
| M-02 | L→V 순서로 투입(오조합) | 버퍼 0, 재료/레시피는 유지 |
| M-03 | L 선택 뒤 패널 닫고 재열기 | 선택 상태 없음, 투입 안 된 상태 |
| M-04 | L 투입 뒤 개인 복귀 | 버퍼에 L 유지, 역할 유지 |
| M-05 | 완성 후 투입/비우기/재열기 반복 시도 | 병 복제·삭제 없음 |
| M-06 | 사용 거리 밖에서 사용 시도 → 정상 거리에서 재시도 | 첫 시도는 권한 유지(거부), 두 번째 시도에서 1회 소비/수면 확정 |
| M-07 | 완성 상태에서 팀원이 관리자에게 잡힘 | 전원 CH8 복귀, 완성물 권한/병/버퍼 초기화 |

## 전체 재시작 처리

원본 문서가 명시한 표준 절차다(실험실 계열 문서 공통 5단계):

1. 새 입력·피해·예약된 동작을 중지한다.
2. 현재 시도를 종료해 이전 시도의 지연 입력을 무효화한다.
3. 대상자의 로프·탑승 등 이동 제어를 해제하고 안전한 시작 위치로 이동한다.
4. 이 챕터의 장치·문제·권한을 초기 상태로 복원한다. 다른 챕터의 진행은 보존한다.
5. 안전 복귀 완료를 확인한 후 준비 상태로 돌아간다. 개인 복귀는 본문에 지정한 항목만
   초기화한다.
