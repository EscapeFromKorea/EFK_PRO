# [FEAT] 맵 1~3 스테이지 연결 및 클리어 화면 추가

## 개요 (Overview)

맵 1~3을 순서대로 연결하고 골인 시 클리어 화면에서 다음 스테이지로 이동할 수 있도록 했습니다. 맵별 골인 조건과 플레이어 색상을 정리하고 맵 2의 조명을 조정했습니다.

## 관련 이슈 (Related Issues)

- 연결된 이슈 없음
- 기준 브랜치: `map-integration`

## 변경 사항 (Changes)

- `LevelManager` 프리팹에 씬 배열을 구성하고, 클리어 화면에 게임을 종료하는 `Home`과 다음 맵으로 이동하는 `Next Stage`를 추가했습니다. 마지막 스테이지에는 비활성화된 `Last Stage Clear`가 표시됩니다.
- 맵 1의 골인 영역을 `P12_Summit_Crown` 위치에 배치하고 `Checkpoint_P12`의 체크포인트 기능을 유지했습니다.
- 맵 2의 기존 출구 조건을 클리어 화면에 연결하고, 맵 3은 부품 진행 여부와 관계없이 `GOAL_FinalExitTrigger` 진입 시 클리어하도록 변경했습니다.
- 정지된 시간에 카메라 보간이 실행되어 발생하는 NaN 오류를 방지했습니다.
- 맵 2·3의 플레이어 머티리얼을 맵 1과 일치시키고, 맵 2의 주변광과 방향광·그림자 설정을 맵 3 기준으로 조정했습니다.
- 맵 1 씬 이름 변경과 빌드 씬 등록, 맵 1의 기존 씬 변경 및 맵 3의 오브젝트 위치·활성화·그림자 설정 변경을 포함했습니다.
- [맵 2 제작 필요 에셋](../map2-asssets/맵2%20제작%20필요%20에셋.md)을 필수 에셋과 추가 제안으로 정리했습니다.

## 테스트 방법 (How to Test)

1. 맵 1에서 `Checkpoint_P12`가 저장만 수행하고, `P12_Summit_Crown`에 도달했을 때 클리어 화면이 표시되는지 확인합니다.
2. `Next Stage`로 맵 2에 이동하고 카메라 NaN 오류가 발생하지 않는지 확인합니다. 열쇠 획득 후 상단 출구를 지나 아래 착지 지점으로 이동해 클리어합니다.
3. 맵 3에서 부품 수집이나 오르골 활성화 없이 `GOAL_FinalExitTrigger`에 진입해 클리어 화면과 비활성화된 `Last Stage Clear`를 확인합니다.
4. 각 클리어 화면에서 `Home`과 다음 스테이지 동작을 확인하고, 맵 2·3의 도형 색상과 맵 2의 조명·그림자를 확인합니다.
5. `LevelManager` 프리팹의 씬 배열을 확인하고, 새 씬 추가 시 `Tools > Level Integration > Sync Build Scenes`로 빌드 목록을 동기화합니다.

**예상 결과:** 맵 1~3에서 각각 지정된 골인 조건에 따라 클리어 화면이 열리고, 다음 맵이 있으면 이동할 수 있습니다.

## 리뷰 포인트 (Review Focus)

- 맵 1 왕관의 골인 범위가 실제 동선과 맞는지 확인이 필요합니다.
- 맵 2의 조명과 맵 2·3의 도형 색상은 Unity에서 시각 확인이 필요합니다.
- 맵 3 씬의 오브젝트 배치·활성화·그림자 변경이 의도에 맞는지 확인이 필요합니다.
- 새 맵은 씬 배열에 추가하고 골인 트리거에 `LevelGoal`을 연결해야 합니다. 에디터 테스트 전에 빌드 씬 동기화가 필요하며 빌드 시 자동 동기화됩니다.
