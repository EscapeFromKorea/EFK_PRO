## 1. 기획 의도 / 목적

감시 담당이 위험을 실시간으로 동료에게 전달하고, 책·혼합 두 작업자가 조합을 완성해 추격자를
무력화하는 구조다. **CH1 추격자의 이동/모델은 재사용하되 상태(순찰/의심/추격/수면)는 CH1과
완전히 독립**이다 — 신규 전투·HP·사망 보상 시스템은 만들지 않는다.

- 감지·추격 로직, 수면/열쇠 연결, 잡힘에 의한 팀 실패 전달을 이 문서가 새로 만든다.
- 재료 조합 판정은 `docs/PRD/ReagentMixing.md`가 담당한다 — 이 시스템은 조합법을 모른다.
  사용 요청을 받아 "수락할지"만 판정한다.

## 2. 동작 시나리오

1. 책·혼합·감시 역할을 선택한다(`RoleClueTerminal` 역할 슬롯 재사용). 감시 담당은 관리자의
   방향과 상태를 관찰해 동료에게 위험을 알린다.
2. 관리자가 시야 안의 참가자를 감지거리(`D`)에서 발견하면 주황색으로 "의심"을 표시한다.
   그 대상이 절반 거리(`D/2`)까지 가까워지면 빨간색 "추격"으로 전환된다. 실제 `D` 수치는
   미정이다.
3. 작업자들은 조합을 완성하고(`ReagentMixing`) 관리자 사용 지점에서 완성물을 사용한다.
4. 유효한 사용으로 잠든 관리자는 **챕터를 떠날 때까지 다시 깨지 않는다.** 참가자는 열쇠를
   얻고 기존 출구 조건에 따라 탈출한다.
5. 잠들기 전에 한 명이라도 관리자에게 잡히면 **전원이 CH8 시작으로 복귀**한다. CH1~7의 진행은
   그대로 보존된다. 시험 모드에서는 감시·잡힘을 끄고 조합/사용 흐름만 확인할 수 있다
   (§4 "시험 감시 생략").

## 3. 컴포넌트 / 스크립트 설계

예상 폴더: `Assets/ManagerSurveillanceSystem/`. `docs/PRD/PathChaser.md`가 정의하는
`Assets/PathChaserSystem/`의 이동/모델 코드를 참조해 재사용하되, **그 폴더의 파일은 수정하지
않는다** — CH8 전용 상태는 이 폴더 안에서 독립적으로 갖는다(교차 폴더 하드 룰 준수, CH1과
상태 공유 없음).

- **`ManagerAgent`** (`C8_MANAGER`) — 순찰 경로(`C8_ROUTE`), 상태(순찰/의심/추격/수면),
  이동을 갖는다. `PathChaserSystem`의 이동 컴포넌트(`PathChaserAgent`)를 참조/재사용.
- **`ManagerFieldOfView`** (`C8_FOV`) — 거리·시야각·차폐 검사. 의심 판정(`거리 ≤ D`)과
  추격 판정(`거리 ≤ D/2`)을 같은 프레임에서 함께 평가한다 — 갑자기 가까이 나타난 대상이
  주황을 거치지 않고 바로 빨강이 될 수 있다는 뜻이며, 이는 확정 동작이다.
- **`ManagerCatchZone`** (`C8_CATCH`) — 잡힘 접촉 영역. 깨어 있고 잡힘이 활성인 관리자의
  지정 영역에 살아 있는 참가자가 들어온 사건만 잡힘으로 인정한다(단순 거리/빨간색만으로는
  잡히지 않는다). 영역 크기는 모델/도형 콜라이더 실측 후 설정.
- **`ManagerStatusIndicator`** (`C8_STATUS`) — 순찰/주황/빨강 표시(아이콘/소리).
- **`ManagerUseValidator`** (`C8_USE`가 보낸 요청을 받는 수신자) — 사용 검증: 현재 시도 ·
  정식 관리자 · 사용 거리 · 살아 있는 요청자 · 팀 완성물 보유 · 관리자가 깨어 있음 · 팀 실패
  미확정을 모두 확인한 뒤에만 수락한다. 수락 시 완성물 소비 + 수면 확정을 **함께** 처리한다
  (`ReagentMixing`의 `TeamCompletionToken`을 소비).
- **`ManagerKeyPoint`** (`C8_KEY_POINT`) — 수면 후 노출되는 열쇠. 물리로 굴리지 않는 획득
  표시물, 직접 상호작용으로 팀 권한 1개 부여. 개인 복귀로 잃지 않는다.

## 4. 확정값 / 기본값

**상태 전이표** (원본 문서 그대로):

| 현재 | 조건 | 다음 동작/표시 |
|---|---|---|
| 준비 | 필수 역할 배정 + 시작 | 순찰·감지·잡힘 켜기 |
| 순찰 | 보이는 대상 거리 ≤ D | 대상 쪽 바라보기, 순찰 이동 멈춤, 주황 + 의심 아이콘 |
| 의심 | 보이는 대상 거리 ≤ D/2 | 빨강 + 추격음, 해당 대상 추격 |
| 의심 | 보이는 대상 없음이 S 지속 | 순찰 복귀 |
| 추격 | 현재 대상 보임 | 마지막 확인 위치 갱신, 추격 계속 |
| 추격 | 대상 안 보임 | 마지막 확인 위치까지 이동, 안 보인 시간이 S 도달 시 순찰 복귀 |
| 활동 상태 | 유효 잡힘 접촉 | 팀 실패 확정, 모든 장치 정지, 전원 CH8 재시작 |
| 활동 상태 | 유효 수면 사용 | 수면 확정, 잡힘/이동/감지 OFF |
| 수면 | 시간 경과/키 획득/출구 대기 | 계속 수면 |

| 항목 | 확정 내용 |
|---|---|
| 의심/추격 거리 비율 | 의심 = `D`, 추격 = `D/2`(정해진 요구) |
| 시야 판정 | 바라보는 방향과 대상 방향 사이 각도 ≤ `F/2`, 지정 차폐물에 막히면 안 보이는 것으로 처리 |
| 즉시 빨강 진입 | 순찰 중 바로 `D/2` 안에 나타난 대상도 같은 판정에서 의심·추격을 함께 평가해 곧바로 빨강이 될 수 있다 — 주황을 반드시 거치게 하는 유예 시간은 넣지 않는다 |
| 표적 선정 | 처음 획득 시 가장 가까운 보이는 대상, 동거리면 고정 참가자 ID 순. 현재 표적이 유효한 동안은 바꾸지 않는다 |
| 표적 무효화 | 추격 해제 → 순찰 복귀 후에만 재획득 |
| 잡힘 정의 | 깨어 있고 잡힘이 활성인 관리자의 지정 접촉 영역에 살아 있는 참가자가 들어온 사건. 거리/색상만으로는 잡히지 않음 |
| 잡힘 결과 | 전원 CH8 시작 복귀. 혼합 버퍼·완성물·관리자·열쇠·출구 상태 초기화. **CH1~7 진행은 보존** |
| 수면 지속성 | 챕터 종료까지 유지, 다른 챕터와 독립. 새 CH8 전체 재시작만 활동 상태로 되돌린다 |
| 열쇠 성격 | 물리로 굴리지 않는 획득 표시물, 직접 상호작용으로 팀 권한 1개. 개인 복귀로 잃지 않음. 표시가 사라졌을 때 미획득 상태면 지정점에 복원, 이미 획득했으면 재생성하지 않음 |
| 사용 검증 항목 | 현재 시도 · 정식 관리자 · 사용 거리 · 살아 있는 요청자 · 팀 완성물 보유 · 관리자가 깨어 있음 · 팀 실패 미확정 — 전부 통과해야 수락 |
| 유효 사용 처리 순서 | 완성물 소비 + 수면 상태 확정 → 이동/잡힘/예약 취소 → 수면 연출 → 키 표시 1회. 연출 실패로 수면을 취소하거나 키를 두 개 만들지 않는다 |
| 시험 감시 생략 | 관리자 위치 고정, 감지/잡힘 OFF, 감시 역할 준비 요건 제외. 책·혼합·사용·수면·키·출구 흐름은 그대로 유지 |

| 파라미터 | 타입 | 설명 | 상태 |
|---|---|---|---|
| `D` | `float`(거리, U) | 의심 감지거리(추격은 `D/2`) | 미정, `D > 0` |
| `F` | `float`(각도, °) | 시야각 | 미정, `0 < F ≤ 360` |
| `S` | `float`(초) | 시야 상실 후 순찰 복귀 대기시간 | 미정, `S ≥ 0` |
| 순찰/추격 속도 | `float`(U/s) | | 미정 |
| `U` | `float`(거리) | 완성물 사용 가능 거리 | 미정 |

  확정했으나(§4), 시야 상실 후 복귀·접촉 잡힘의 나머지 세부 판정은 원본이 "미결정 세부
  동작안"으로 남긴 항목이 더 있을 수 있다 — 구현 착수 시 재확인.
- **동시 처리(잡힘 vs 유효 사용) 우선순위**: 원본이 제안한 동작안 — "같은 판정 묶음"(한 번의
  게임 상태 갱신에서 함께 들어온 잡힘과 사용 요청)에서는 **잡힘을 먼저 처리**한다. 실패가
  확정되면 완성물로 취소할 수 없고, 이미 수면인 관리자는 접촉 사건 자체를 만들지 않는다.
  이 규칙은 원본이 "미결정 동작안"으로 표시했으나 완료 조건 A-07이 이 규칙을 전제로 검증
  절차를 명시하고 있어, **이 PRD는 이를 기본 채택안으로 삼는다** — 다른 우선순위를 원하면
  구현 전에 확인 필요.
- **감지거리 등 전체 수치**: `D/F/S`/속도/`U` 전부 미정, 배치 시험 후 결정.

## 전체 재시작 처리

원본 문서가 명시한 표준 절차다(실험실 계열 문서 공통 5단계):

1. 새 입력·피해·예약된 동작을 중지한다.
2. 현재 시도를 종료해 이전 시도의 지연 입력을 무효화한다.
3. 대상자의 로프·탑승 등 이동 제어를 해제하고 안전한 시작 위치로 이동한다.
4. 이 챕터의 장치·문제·권한을 초기 상태로 복원한다. 다른 챕터의 진행은 보존한다.
5. 안전 복귀 완료를 확인한 후 준비 상태로 돌아간다. 개인 복귀는 본문에 지정한 항목만
   초기화한다.
