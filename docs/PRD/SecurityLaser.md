# 조준 예고 보안 레이저 (Security Laser) — PRD

> 독립 신규 기믹. **CH4가 원 소유**(캐릭터별 조준 고정 모드)이고, **CH5가 같은 시스템의 더
> 단순한 모드(고정 방향 주기)를 별도 인스턴스로 재사용**한다 — `docs/PRD/PathChaser.md`(CH1→CH8
> 재사용), `docs/PRD/ProjectileTrap.md`(CH3→CH5 재사용)에 이은 **세 번째 챕터 간 재사용
> 시스템**이다. 출처: Notion "요구사항명세서" — `[실험실 CH4] 조준 예고 보안 레이저`.
> 상태: **기획 단계 — PRD 작성만 완료, 구현 전.** 이번 계획으로 잡은 실험실 신규 시스템
> 10개 중 마지막 문서다.

## 1. 기획 의도 / 목적

특정 순간의 조준을 보고 피하는 **개인 컨트롤** 과제다. CH4는 캐릭터별 전용 센서 3개가 각자
독립적으로 "지금 이 순간의 위치"를 조준 고정한 뒤 지연을 두고 발사한다 — 실시간 추적이
아니라 **스냅샷 조준**이라는 점이 핵심이다. CH5는 같은 레이저 표시/판정 기술을 재사용하되
조준 로직 없이 **고정 방향으로 주기 반복만** 한다(§1의 두 모드 구분).

- CH4: 발사 → 1초 뒤 재조준 → 2초 뒤 재발사(캐릭터별 완전 독립 타이머).
- CH5: 예고(`W`) → 발사(`B`) → 휴식(`R`) 반복, 방향 변경 없음. **CH4의 1초/2초 값을 그대로
  복사하지 않는다** — 별도 파라미터.
- 한 번 맞은 플레이어만 레이저 구간 시작으로 복귀한다. CH4 낙석 구간의 시작점과는
  **다른 목적지**다(같은 챕터 안에서도 원인별로 목적지가 갈린다 — `docs/PRD/SectionRespawn.md`
  §1의 설계 충돌 해소 사례와 동일한 패턴).

## 2. 동작 시나리오 (CH4 — 조준 고정 모드)

1. 각 캐릭터 전용 센서가 조준을 고정한 위치를 예고선으로 보여준다.
2. 플레이어는 고정된 예고선 밖으로 이동한다. **센서는 고정 이후의 플레이어 움직임을 쫓아
   예고선을 계속 옮기지 않는다** — 스냅샷 이후로는 정지된 목표다.
3. 레이저가 발사된 시점부터 1초 뒤 새 위치를 조준하고, 그때부터 2초 뒤 다시 발사한다. 세
   캐릭터의 레이저는 각각 독립적으로 동작한다.
4. 고정 레이저가 제한하는 통로 안에서 이 예고를 보고 회피한다.
5. 한 번 맞은 플레이어만 레이저 구간 시작으로 돌아간다(낙석 구간 시작으로 되돌리지 않는다).

## 3. 컴포넌트 / 스크립트 설계

예상 폴더: `Assets/SecurityLaserSystem/`.

- **`CharacterLockedLaser`** (CH4 전용) — 센서마다 **고유 대상 캐릭터 ID**를 지정한다.
  **"현재 조작 중인 캐릭터" 참조로 세 센서를 공통 연결하지 않는다** — Tab으로 조작 대상을
  바꿔도 센서의 대상은 바뀌지 않는다(확정, 완료 조건 L-02). 상태 `조준 고정 → 대기(1초) →
  발사 → 대기(2초) → 조준 고정`을 반복한다.
- **`FixedPeriodicLaser`** (CH5 전용, 더 단순한 변형) — 방향 고정, 조준 로직 없음. 상태
  `예고(W) → 발사(B) → 휴식(R)`만 반복한다. `CharacterLockedLaser`와 발사선 렌더링/차폐 판정
  로직은 공유하되(공통 베이스 또는 유틸리티로 분리), 조준·재조준 로직은 갖지 않는다.
- **공통 레이저 판정**: 발사점·사거리·광선 폭·차폐 레이어를 인스펙터로 노출. **발사선의
  시각 표현과 실제 판정 데이터는 동일한 시작/종점을 참조**한다(따로 두면 눈에는 안 맞았는데
  맞은 판정이 나는 불일치가 생긴다). 벽 첫 충돌점까지만 광선을 표시/판정하고, 벽 뒤나 예고선
  자체는 무피해.
- **개인 복귀 연결**: `docs/PRD/SectionRespawn.md`의 목적지 지정 개인 복귀 재사용. CH4는
  목적지 `"레이저 구간 시작"`(낙석 시작과는 별개), CH5는 목적지 `"CH5 시작"`.

## 4. 확정값 / 기본값

**CH4 시간표** (원본 문서 그대로, 최초 활성화 시점 t=0 기준):

| 시각 | 상태/사건 | 피해 |
|---|---|---|
| t=0 | 최초 조준 고정 · 예고선 표시 | 없음 |
| t=2 | 첫 발사 | 활성 광선에만 있음 |
| t=3 | 재조준 고정 · 새 예고 | 없음 |
| t=5 | 두 번째 발사 | 있음 |
| t=6 | 재조준 | 없음 |

이후 동일 패턴 반복(발사 후 1초 뒤 재조준, 재조준 후 2초 뒤 발사).

| 항목 | 확정 내용 |
|---|---|
| 센서-캐릭터 매핑 | 센서마다 고유 대상 캐릭터 ID 고정. "현재 조작 캐릭터" 참조 금지 |
| 조준 갱신 시점 | 스냅샷 방식 — 고정 시점 이후의 대상 이동을 쫓아가지 않는다 |
| CH4/CH5 파라미터 독립 | CH5는 `W/B/R` 자체 파라미터를 쓴다. CH4의 1초/2초 값을 그대로 복사하지 않는다 |
| 시각/청각 구분 | 예고 = 점선 + 조준음, 발사 = 굵은 실선 + 발사음 |
| 판정 범위 | 벽 첫 충돌점까지만 광선 표시/판정. 벽 뒤·예고선은 무피해 |
| 발사선-판정 일치 | 시각 표현과 실제 판정이 동일한 시작/종점 데이터를 공유해야 한다 |
| 전체 종료 | 피해 끄기 → 예약된 발사 취소 → 선 제거 |
| 개인 복귀 영향 범위 | 개인 복귀는 본인 센서만 대기시키고, 동료 센서의 타이머는 그대로 진행 |
| 복귀 목적지 구분 | CH4는 "레이저 구간 시작"(낙석 시작과 별개), CH5는 "CH5 시작" |

| 파라미터 | 타입 | 설명 | 상태 |
|---|---|---|---|
| 발사 후 재조준 지연 (CH4) | `float`(s) | 확정값 1초 | **확정** |
| 재조준 후 발사 지연 (CH4) | `float`(s) | 확정값 2초 | **확정** |
| 광선 유지시간 `B` | `float`(s) | 다음 재조준과 겹치지 않아야 함 | 미정, 제안 범위 `0 < B < 1`초(제안일 뿐 확정 아님) |
| `W`/`B`/`R` (CH5) | `float`(s) | 예고/발사/휴식 | 미정, CH4 값 복사 금지 |
| 사거리, 광선 폭, 차폐 레이어 | | | 미정 |
| CH4 고정 장애물 상시 위험 여부 | `bool` | 상시 위험(단 우회/점프 통과 가능 공간은 레벨 디자인으로 반드시 확보) | **확정(2026-09-21)** |
| 최초 발사 지연 (CH4) | `float`(s) | 최초 조준 고정 후 첫 발사까지의 지연. 기본값 2초, 인스펙터에서 조정 가능하게 노출 | **확정(2026-09-21)**, 기본값 2초 |

## 6. 완료 조건 대비 검증

| ID | 준비/행동 | 기대 |
|---|---|---|
| L-01 | 고정 뒤 대상이 옆으로 이동 | 원래 고정된 방향으로 발사됨. t=2/5/8에 발사, t=3/6에 재조준 |
| L-02 | Tab으로 조작 대상 전환 | 센서의 대상 캐릭터 ID는 바뀌지 않음 |

| L-05 | 벽 뒤에 도형 배치 | 벽 뒤로 피해/빛이 관통하지 않음 |
| L-06 | 다른 도형이 A의 광선 경로를 통과 | 교차 피격 동작안 확정 기준에 따라, 통과한 도형만 자기 레이저 구간 시작으로 복귀 |
| L-07 | CH5 고정 모드 시험 | 끝까지 방향 고정 유지, 피격 목적지는 CH5 시작 |

수치/배치를 완성으로 표시하지 않는다.

## 전체 재시작 처리

원본 문서가 명시한 표준 절차다(실험실 계열 문서 공통 5단계):

1. 새 입력·피해·예약된 동작을 중지한다.
2. 현재 시도를 종료해 이전 시도의 지연 입력을 무효화한다.
3. 대상자의 로프·탑승 등 이동 제어를 해제하고 안전한 시작 위치로 이동한다.
4. 이 챕터의 장치·문제·권한을 초기 상태로 복원한다. 다른 챕터의 진행은 보존한다.
5. 안전 복귀 완료를 확인한 후 준비 상태로 돌아간다. 개인 복귀는 본문에 지정한 항목만
   초기화한다.
