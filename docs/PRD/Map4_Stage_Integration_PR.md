# [FEAT] 맵 4 스테이지 연결 및 최종 클리어 추가

## 개요 (Overview)

실험실 맵을 네 번째이자 마지막 스테이지로 연결했습니다. 맵 3 클리어 후 맵 4로 이동하며, 최종 체크포인트에 도달하면 공통 클리어 화면이 표시됩니다.

## 관련 이슈 (Related Issues)

- 연결된 이슈 없음
- 기준 브랜치: `map-integration`

## 변경 사항 (Changes)

- 맵 4 에셋을 `Assets/LaboratoryMap4`에서 `Assets/Scenes/Map4_Laboratory`로 이동했습니다.
- `LevelManager`의 마지막 항목에 `Map4_Master` 씬을 추가하고 마스터 씬과 섹터 8개의 빌드 설정 경로를 갱신했습니다.
- 맵 4의 `S8_FinalExit_Checkpoint` 트리거에 도형이 진입하면 공통 클리어 화면이 열리도록 연결했습니다. 마지막 스테이지이므로 `Last Stage Clear` 버튼이 비활성화됩니다.
- 맵 4에서 기존 탈출 완료 안내가 공통 클리어 화면보다 먼저 표시되지 않도록 했습니다. 기존 출구의 도형 모으기와 체크포인트 처리는 유지합니다.
- 맵 4 플레이어 세 도형의 머티리얼을 맵 1과 일치시키고, 플레이어 프리팹 재생성 시에도 같은 머티리얼이 적용되도록 했습니다.
- `Open All Sectors` 메뉴와 주요 맵·플레이어 생성 도구의 경로를 이동된 폴더에 맞췄습니다.

## 테스트 방법 (How to Test)

1. 맵 3을 클리어하고 `Next Stage`를 눌러 맵 4 마스터 씬으로 이동합니다.
2. 섹터 8개가 로드되고 세 도형이 시작 위치에 배치되는지 확인합니다.
3. 맵 4의 구·정육면체·정사면체 색상이 맵 1과 동일한 머티리얼을 사용하는지 확인합니다.
4. 마지막 출구를 통과한 뒤 `S8_FinalExit_Checkpoint`에 도형을 이동시켜 공통 클리어 화면이 표시되는지 확인합니다.
5. `Last Stage Clear`가 비활성화되어 있는지, `Home`이 게임을 종료하는지 확인합니다.
6. 에디터에서 `Tools > Laboratory Map4 > Open All Sectors`를 실행해 마스터 씬과 섹터가 열리는지 확인합니다.

**예상 결과:** 맵 3에서 맵 4로 정상 이동하고, 마지막 체크포인트에 닿으면 최종 클리어 화면이 표시됩니다.

## 리뷰 포인트 (Review Focus)

- 맵 4는 마스터 씬에서 섹터 8개를 실행 중 추가 로드합니다. 모두 로드한 뒤 플레이어를 배치하므로 시작 시 로딩과 스폰 위치를 확인해 주세요.
- 기존 출구 흐름은 열쇠 문과 관리자 상태 조건을 충족하면 세 도형을 최종 구역으로 모읍니다. 공통 클리어 화면은 그 뒤 체크포인트 진입 시 표시됩니다.
- 에셋 이동 후에도 일부 맵 4 편집·검증 도구에는 이전 `Assets/LaboratoryMap4` 경로가 남아 있습니다. 해당 도구를 사용할 때 추가 수정이 필요합니다.
- 씬을 에디터에서 미리 여러 개 열어 둔 경우와 일반적인 맵 3 → 맵 4 전환 모두에서 골인 판정을 확인해 주세요.
