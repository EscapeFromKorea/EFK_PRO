# 서버실 전력 유지 장치 (Server Room Power) — PRD

> 독립 신규 기믹. 실험실 CH7 전용 오케스트레이터. `docs/PRD/RoleClueTerminal.md`(역할 슬롯 +
> 문답 단말)와 `docs/PRD/WiringPanel.md`(연결 퍼즐)를 소비해 조립한다.
> 출처: Notion "요구사항명세서" — `[실험실 CH7] 서버실 전력 유지 장치`.
> 상태: **기획 단계 — PRD 작성만 완료, 구현 전.** 선행 문서(역할 단말, 배선 패널) PRD가
> 먼저 확정되어 있어야 이 문서의 신호 계약을 구현할 수 있다.

## 1. 기획 의도 / 목적

세 번째 참가자(전력 담당)가 연결 규칙을 계속 풀어서 나머지 두 참가자(책/컴퓨터 담당)의
문제 풀이 시간을 확보해 주는 구조다. 이 문서는 **오케스트레이터**로서 아래 세 컴포넌트를
연결하는 역할만 한다 — 각 컴포넌트 자체의 판정 로직은 재구현하지 않는다.

- 역할 배정·책/문제 표시·정오답 판정: `docs/PRD/RoleClueTerminal.md`(아래 §3에서 이 시스템의
  `QuizTerminal`을 소비한다)
- 전력 담당의 연결 퍼즐: `WiringPanel`
- 이 문서가 새로 만드는 것: **전력 게이지(감소/회복)**, **제출 가능 여부 게이트**,
  **회로 순환 배정**, **자동 유지(시험용) 옵션**.

## 2. 동작 시나리오

1. 책·컴퓨터·전력 세 역할이 모두 배정된 뒤 컴퓨터 담당이 "실험 시작"을 누르면 전력 게이지가
   줄어들기 시작한다.
2. 전력 담당은 `WiringPanel`의 규칙표를 보고 선을 연결한다. 회로 하나를 완성하면 전력이
   회복되고, 휴식 시간 후 다음 회로가 배정된다.
3. 전력이 임계치 아래로 떨어지면 컴퓨터 담당의 **답 제출만** 막힌다. 책 읽기와 배선 조작은
   계속 가능하고, 이미 맞힌 문항은 그대로 유지된다.
4. 전력이 0이어도 배선으로 계속 복구할 수 있다. 복구 임계치에 도달하면 같은 미완료 문제의
   제출이 다시 가능해진다.
5. 모든 문답이 끝나면 전력 감소와 새 회로 배정이 함께 멈춘다.
6. **자동 유지 시험 모드**에서는 전력 담당 없이 진행 가능 — 전력은 최대치로 고정되고 회로/정전
   로직이 꺼진다. 입구 배선과 문답은 이 모드에서도 그대로 필수다.

## 3. 컴포넌트 / 스크립트 설계

예상 폴더: `Assets/ServerRoomPowerSystem/`. 다른 두 시스템의 파일은 수정하지 않고, 이 폴더의
컨트롤러가 그쪽이 발신하는 신호를 구독하는 방향으로만 연결한다(교차 폴더 하드 룰 준수).

- **`PowerMaintenanceController`** (챕터당 1개, 상태 보유자) — §4 상태표를 구현. 전력값 `E`,
  현재 회로 배정번호, 자동 유지 여부를 갖는다.
  - `WiringPanel`의 완료 신호를 구독해 `E = min(M, E + G)`를 적용하고 다음 회로를 배정한다
    (`docs/PRD/WiringPanel.md` §3의 `{장치, 시도, 배정번호, 회로ID}` 계약을 그대로 사용).
  - `RoleClueTerminal`의 `QuizTerminal`에 **제출 가능 여부**(`E ≥ U`가 되기 전까지 `false`)를
    공개 프로퍼티/이벤트로 노출한다 — `docs/PRD/RoleClueTerminal.md` §5가 "구현 시 확정"으로
    남긴 신호 계약이 바로 이것이다. 제안: 연속값(`E`, `submitLocked`)은 프로퍼티 폴링 또는
    작은 인터페이스로, "잠김/해제 전환" 이산 이벤트는 `UnityEvent<bool>` 병행.
- **`PowerGauge`** (표시 전용) — 전력값을 시각화. 판정 로직 없음.
- **`AutoMaintainToggle`** — 시작 전에만 선택 가능한 시험 옵션. 켜면 전력 역할을 준비 요건에서
  제외하고 `E = M` 고정, 회로/정전 로직을 비활성화한다. 시작 후 옵션 변경은 거부하고 재시작을
  안내한다.

## 4. 확정값 / 기본값

| 상태 | 조건/행동 | 결과 |
|---|---|---|
| 준비 | 역할 3개 배정 + 시작 입력 | `POWER_1` 배정, 시간 감소 시작 |
| 유지 | 활성 시간 `Δt` 경과 | `E = max(0, E - d×Δt)` |
| 유지 | 현재 회로 완료(`WiringPanel` 신호) | `E = min(M, E + G)`, 배정당 1회만 회복, 휴식 후 다음 회로 |
| 유지 | `E < K` | 컴퓨터 제출 잠금, 배선/책 읽기는 계속 가능 |
| 전력 부족 | `E ≥ U` | 컴퓨터 제출 잠금 해제 |
| 모든 진행 | 문답 전체 성공 | 전력 감소·회로 예약 정지, 출구 목표 충족 신호 |

| 항목 | 확정 내용 |
|---|---|
| 파라미터 관계 | `0 ≤ E0 ≤ M`, `d ≥ 0`, `G > 0`, `0 < K < U ≤ M`. `K`는 반드시 양수(전력 0에서는 항상 제출 잠김 보장). 시작 전력 `E0 ≥ U` 필요 |
| 잠금/해제 이력 없음 | `E = K`는 새로 잠그지 않는다(잠긴 상태가 아니었다면). 이미 잠긴 경우 `E = K`로는 안 풀리고 `E ≥ U`까지 회복해야 함(히스테리시스 — 경계값 근처에서 잠금이 초당 여러 번 토글되는 것을 방지) |
| 회로 순환 | `POWER_1 → 2 → 3 → 1 → ...`, 매 배정마다 배정번호 증가. 휴식 `H`초 후 새 회로 배정, 휴식 중에도 전력은 계속 감소 |
| 최대치 성공 | 최대 전력에서 회로를 완성해도 회로는 소모되고, 초과 회복량은 저장하지 않는다(버림) |
| 오배선 | 추가 차감 없음. 전력 0에서도 배선 시도 가능 |
| 정전 중 문항 상태 | 제출만 잠기고, 이전에 맞힌 문항과 입구 문 상태는 보존 |
| 이벤트 순서 | 입력 수락 전 해당 시각까지 전력 감소를 먼저 반영. 같은 시각에 회로 회복과 제출 요청이 겹치면 **회복 처리 → 제출 허용 여부 검사** 순서로 처리 |
| 정답 취소 없음 | 제출 수락 뒤에 전력이 떨어져도 이미 인정된 정답은 취소되지 않는다 |
| 역할 재배정 대기 영향 | 전력/회로/제출을 함께 멈춘다(개인 메뉴는 안 멈춤). 개인 복귀는 공용 전력 상태에 영향 없음(전력은 챕터 공용 자원) |
| 전체 재시작 | 감소·예약 취소 → `E0`로 복원 → 회로/배정번호 초기화 → 준비 상태. 종료된 시도의 지연 회복 신호는 무효 |
| 자동 유지 모드 | 시작 전에만 선택. `E = M` 고정, 회로 배정·정전 로직 비활성. 전력 역할만 준비 요건에서 제외(입구 배선·문답은 여전히 필수). 시작 후 옵션 변경 거부 |

| 파라미터 | 타입 | 설명 | 상태 |
|---|---|---|---|
| `M`/`E0`/`K`/`U` | 전력 단위 | 최대치/시작값/잠금 임계/해제 임계 | 수치 미정 |
| `d` | 전력/s | 초당 소모율 | 미정 |
| `G` | 전력/회로 | 회로 완성당 회복량 | 미정 |
| `H` | s | 회로 사이 휴식시간 | 미정 |

## 6. 완료 조건 대비 검증

| ID | 조건/행동 | 기대 |
|---|---|---|
| E-01 | 준비 상태에서 시간 진행 | 전력 변화 없음 |
| E-02 | `E`를 `K`보다 작게 만들기 | 제출만 잠김, 책 읽기/배선은 가능 |
| E-03 | 0에서 배선을 반복해 `U`까지 회복 | 복구되어 같은 미완료 문제 제출 재개 가능 |
| E-04 | 동일 배정 회로를 2번 완료 시도 | `G`는 1번만 회복 |
| E-05 | 같은 활성 시간을 다른 프레임 간격으로 진행 | 설정한 계산 정밀도 내에서 같은 전력값 |
| E-06 | 마지막 문항 성공 후 시간 진행 | 감소·새 회로 배정·정전 없음 |
| E-07 | 자동 유지 모드로 진행 | 전력 역할 없이 시작·완료 가능, 입구 배선/문답은 생략되지 않음 |

## 전체 재시작 처리

원본 문서가 명시한 표준 절차다(실험실 계열 문서 공통 5단계):

1. 새 입력·피해·예약된 동작을 중지한다.
2. 현재 시도를 종료해 이전 시도의 지연 입력을 무효화한다.
3. 대상자의 로프·탑승 등 이동 제어를 해제하고 안전한 시작 위치로 이동한다.
4. 이 챕터의 장치·문제·권한을 초기 상태로 복원한다. 다른 챕터의 진행은 보존한다.
5. 안전 복귀 완료를 확인한 후 준비 상태로 돌아간다. 개인 복귀는 본문에 지정한 항목만
   초기화한다.
