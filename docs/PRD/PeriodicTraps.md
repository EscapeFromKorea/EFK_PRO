# 주기형 물리 함정 — 도끼·망치·가시 (Periodic Traps) — PRD

> 독립 신규 기믹. 실험실 CH5 전용. 출처: Notion "요구사항명세서" —
> `[실험실 CH5] 주기형 물리 함정 — 도끼·망치·가시`.
> 상태: **기획 단계 — PRD 작성만 완료, 구현 전.** 저장소에 재사용 가능한 "주기 운동/예고"
> 공용 컴포넌트가 없음을 확인했다(`FallingRockSystem`이 유일한 인접 사례지만 그건 낙하하는
> dynamic Rigidbody 스폰 방식이라 왕복/승강 운동과는 다른 문제다) — 세 유형 모두 새로 만든다.
> 스코프 메모: CH5 "함정 외다리" 시퀀스에 등장하는 **측면 발사 구간은 이 문서가 아니라**
> `docs/PRD/ProjectileTrap.md`(CH3 원 소유, CH5는 별도 인스턴스로 재사용)가 담당한다.

## 1. 기획 의도 / 목적

CH5에서 궤적·상부·바닥을 번갈아 관찰하며 안전한 출발 시점을 스스로 판단하게 만드는 회피형
함정 3종이다. 운동 로직은 유형마다 다르지만 **공통 뼈대(시작/정지/주기/예고/유효 접촉 알림)는
하나로 묶는다** — "세 유형을 하나의 거대한 코드로 합치라는 요구는 아니다"라는 원본 명시를
따라, 공통 뼈대는 공유하되 각 유형의 운동·판정 로직은 독립 컴포넌트로 분리한다.

- **CH5에서 맞은 도형만 CH5 시작으로 복귀**한다 — `docs/PRD/SectionRespawn.md`의
  `SectionSafePoint`(목적지: "CH5 시작") + `SectionHitCounter`(임계값 1 = 즉시 복귀)를
  그대로 재사용한다. 새 복귀 로직을 만들지 않는다.
- 도형별 차등 판정(구/정육면체/정사면체)은 원본에 명시가 없다 — **모든 도형에 동일하게
  적용**한다.

## 2. 동작 시나리오

1. 안전 발판에서 도끼의 왕복 궤적, 망치의 바닥 예고, 또는 가시 바닥판의 예고를 관찰한다.
2. 위험부가 통로를 비우는 시점에 이동해 다음 안전 발판에 도착한다.
3. 도끼는 보이는 날, 망치는 내려치는 머리, 가시는 돌출부의 판정에 맞춰 회피한다(§4 유형별
   위험/무피해 시점 표).
4. 맞은 플레이어만 CH5 시작으로 복귀한다. 다른 플레이어의 위치와 움직이는 함정의 주기는
   그대로 유지된다(개인 복귀가 공용 주기를 되돌리지 않는다).

## 3. 컴포넌트 / 스크립트 설계

저장소 공통 발신자-수신자 패턴을 따른다. 예상 폴더: `Assets/PeriodicTrapSystem/`.

- **`PeriodicTrapBase`** (공통 뼈대, 세 유형이 상속 또는 합성) — 시작/정지 신호, 위상 지연
  (`startPhase`), 활성 위험부 접촉을 "장치·주기·대상당 1회"로 제한하는 중복 방지, 유효 접촉
  발생 시 `SectionHitCounter`(임계 1) 발화. 개인 복귀 완료가 이 컴포넌트의 내부 주기/타이머에
  영향을 주지 않는다. **끼임 안전 정지(확정)**: 무피해 이동부가 대상을 고정 벽/바닥 사이에
  압착하는 상태를 감지하면 이동을 멈추고 피해를 OFF로 유지, 대상이 벗어나면 남은 동작을
  이어간다.
- **`AxeTrap`** — 로컬 축 기준 `-A ~ +A` 진자 왕복(왕복 시간 `P`). **양 끝에서 부드럽게
  감속·재가속하는 이징 곡선을 쓴다 — 순간 방향 전환 금지**(확정 요구). 날 영역만 위험 판정,
  손잡이/지지대는 무피해.
- **`HammerTrap`** — 상태 순서 `상부 대기 → 바닥 예고 → 하강 → 저점 대기 → 상승`(반복).
  머리 영역은 하강/저점 상태에서만 위험, 나머지 상태는 무피해.
- **`SpikeTrap`** — 상태 순서 `수납 → 바닥 예고 → 상승 → 돌출 유지 → 하강`(반복). 돌출부는
  상승/돌출 상태에서만 위험, 나머지는 무피해.
- **예고 표시**: 예고 바닥은 **실제 위험 투영 범위와 정확히 같은 크기**로 그린다 — 위험 구간
  밖으로 번지는 그림자를 피해 판정에 쓰지 않는다(확정).
- 재사용 대상 없음 확인됨(문서 상단 메모 참고) — 세 컴포넌트 모두 신규 구현.

## 4. 확정값 / 기본값

**유형별 상태·판정** (원본 문서 그대로):

| 유형 | 상태 순서 | 움직임/피해 |
|---|---|---|
| 도끼 | 시작 예고 → 왕복 반복 | 로컬 축 기준 `-A~+A` 진자, 왕복 시간 `P`. 날만 위험, 손잡이/지지대 무피해 |
| 망치 | 상부 대기 → 바닥 예고 → 하강 → 저점 대기 → 상승 | 하강/저점의 머리만 위험. 상부·예고·상승 무피해 |
| 가시 | 수납 → 바닥 예고 → 상승 → 돌출 유지 → 하강 | 상승/돌출만 위험. 수납/예고/하강 무피해 |

| 항목 | 확정 내용 |
|---|---|
| 도끼 운동 곡선 | 왕복 양 끝에서 부드럽게 속도가 바뀌는 주기 운동. 순간 방향 전환 금지 |
| 예고 판정 범위 | 예고 표시 크기 = 실제 위험 투영 범위. 그 밖은 무피해 판정 |
| 접촉 집계 단위 | 활성 위험부 접촉은 장치·주기·대상당 1회 |
| 개인 복귀 영향 | 개인 복귀가 공용 주기(도끼 위상, 망치/가시 상태 진행)를 되돌리지 않는다 |
| 복귀 목적지 | CH5 시작(`SectionSafePoint`, `SectionRespawn` 재사용) |
| 값 승격 금지 | 그레이박스(임시) 수치를 제품 기본값으로 자동 승격하지 않는다. 제작자가 입력한 값은 시험 설정 기록에 저장 |
| 조립 순서 | (1) 단독 배치 + 안전 관찰 발판 → (2) 이동부 끝 위치/전체 범위가 벽·다른 함정과 안 겹치는지 확인 → (3) 개인 복귀 연결 + 시작/종료 연결 → (4) 단독 통과 시험 완료 후에만 복합 배치 연결 → (5) 위상 지연 설정으로 모든 통로가 동시에 닫히지 않는지 시험 |

| 파라미터 | 타입 | 설명 | 상태 |
|---|---|---|---|
| `A`(최대각), `P`(왕복 시간) | `float` | 도끼 진자 | 미정 |
| 각 상태 지속시간(망치/가시) | `float`(초) | 상부대기/예고/하강/저점/상승 등 | 미정 |
| 초기/끝 위치, 축, 중심, 위험 영역 | `Transform`/필드 | 유형별 배치 데이터 | 미정, **위험 영역 참조 없으면 시작 거부** |
| `startPhase` | `float`(초 또는 위상비) | 여러 장치의 동시 폐쇄 방지용 위상 지연 | 미정(레벨 배치 대상) |

## 전체 재시작 처리

원본 문서가 명시한 표준 절차다(실험실 계열 문서 공통 5단계):

1. 새 입력·피해·예약된 동작을 중지한다.
2. 현재 시도를 종료해 이전 시도의 지연 입력을 무효화한다.
3. 대상자의 로프·탑승 등 이동 제어를 해제하고 안전한 시작 위치로 이동한다.
4. 이 챕터의 장치·문제·권한을 초기 상태로 복원한다. 다른 챕터의 진행은 보존한다.
5. 안전 복귀 완료를 확인한 후 준비 상태로 돌아간다. 개인 복귀는 본문에 지정한 항목만
   초기화한다.
