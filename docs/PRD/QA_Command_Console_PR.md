# [FEAT] 개발용 QA 명령어 콘솔 추가

## 개요 (Overview)

맵의 특정 구간을 반복 검증할 수 있도록 도형 집결, 임시 체크포인트, 도형별 속도·무게 조정을 위한 QA 콘솔을 추가했습니다. Unity 에디터 플레이 모드와 개발 빌드에서 사용할 수 있습니다.

## 변경 사항 (Changes)

- 백틱 키로 화면 왼쪽 하단에 콘솔을 엽니다. 열 때마다 미전송 입력을 비우고, 콘솔이 열린 동안 명령어와 도형 별칭을 계속 표시합니다.
- `gather`는 조작 중인 도형 근처에서 서로 겹치지 않는 바닥 위치를 찾아 도형을 모읍니다. `save`는 노란 구로 표시되는 임시 체크포인트를 만들고, `clear`는 이를 지워 일반 체크포인트로 복귀할 수 있게 합니다.
- `speed <값> [도형]`과 `weight <값> [도형]`은 실행 중인 도형의 능력치를 변경합니다. 도형을 생략하면 전체에 적용됩니다.
- 멀티플레이에서는 호스트만 명령을 실행할 수 있습니다. 이동은 해당 도형을 소유한 참가자에게 전달하고, 임시 체크포인트와 능력치 변경은 다음 라운드에서 초기화합니다.

## 테스트 방법 (How to Test)

1. Unity `6000.3.24f1`에서 맵 1을 실행하고 백틱 키로 콘솔을 엽니다. 텍스트만 입력한 상태에서 닫았다 다시 열어 입력칸이 비워지고 명령어 목록이 남아 있는지 확인합니다.
2. 넓은 발판에서 `gather`를 실행합니다. 일반 체크포인트를 확보한 뒤 `save`와 `R`로 임시 지점 복귀를 확인하고, `clear` 후 다시 `R`을 눌러 일반 체크포인트로 복귀하는지 확인합니다.
3. `speed 9`, `weight 2.5 tetra`를 차례로 입력합니다. 속도는 전체 도형에 적용되고 무게는 정사면체에만 적용되는지 확인합니다.
4. 개발 빌드 멀티플레이에서 호스트의 명령이 참가자에게 반영되고, 다음 라운드에 임시 표시와 조정값이 초기화되는지 확인합니다.

**예상 결과** — 명령 실행 결과가 표시되는 동안에도 명령어 목록을 볼 수 있습니다. 임시 지점을 지우면 마지막으로 확보한 일반 체크포인트를 사용합니다.
