# 맵2 주방 · 섹터별 기믹과 복귀

**2026년 11월 24일 · `feature/map2-kitchen-rebuild`**. 플레이어는 퇴식구에서 세척·정리 라인을 지나 조리대 상단의 문을 열고 배식구로 탈출한다. 아래 수치는 이 브랜치의 [맵2 플레이 씬](../../Assets/KitchenTeamTrial/Map2KitchenTeamTrial.unity) 기준이다.

| 섹터 | 동선과 기믹 | 실패·복귀 및 협동 |
|---|---|---|
| **CH1 · 퇴식구와 쥐** | 경사로와 컨베이어로 세척구까지 올라간다. 쥐가 정해진 경로를 따라 도형을 추격한다. | 도형이 움직이면 쥐가 따라붙는다. 접촉 포획 판정은 아래 추격 설명을 참고한다. |
| **CH2 · 접시 살균기** | 스테인리스 세척 터널 8칸 안에서 물줄기 12개가 기존의 2배 속도로, 서로 다른 타이밍에 좌우를 왕복한다. 빈틈을 보고 전진한다. | 물줄기에 맞은 도형을 해당 줄의 안전 위치로 옮긴다. 외장에 가려지는 부분은 카메라 시야에 따라 숨긴다. |
| **CH3 · 접시 통로** | 건조한 입구의 압력판으로 물줄기를 막고, 이동 접시 세 줄 사이를 두 차례 환승한다. 각 줄에는 접시 5개가 있다. | 한 도형이 압력판을 지켜 동료의 통과를 돕는다. 고온 레일에 닿으면 해당 도형만 지정된 안전 지점으로 복귀한다. 마지막 도형도 차폐판 없이 물줄기를 피해 통과할 수 있도록 구성되어 있다. |
| **CH4 · 설거지 상부** | 감지 영역과 시야 안에서 움직이는 도형을 레이저가 추적한다. 현재 회전 추적 설정은 최대 초당 210도다. | 레이저는 조준 연출이며, 해당 코드에는 피격·사망·복귀 처리가 없다. |
| **CH5 · 싱크대 내부** | 배수구에서 나온 바퀴벌레가 싱크대 내부 경로를 추격한다. 출구의 무게판은 합산 질량 4.0에 도달하면 셔터를 연다. | 네모 3.0과 구 1.0 또는 세모 1.5를 함께 올린다. 셔터가 고정되면 발판을 지키던 도형도 지나간다. 바퀴벌레의 추격 코드에는 접촉 복귀 처리가 없다. 싱글에서는 집결 지점에서 E로 뒤처진 도형을 부를 수 있다. |
| **CH6 · 그릇 정리** | 쥐가 정리대 경계까지 추격한다. 두 분류 밀대가 교대로 작동하며 가운데 대피 홈이 있다. 이후 이동 운반 접시, 협동 다리, 가속 발판 1개, 벽걸이 포충기 1대 순으로 이어진다. | 밀대에 닿은 도형은 회수 접시 위치로 옮겨지고 복귀 경사로를 이용한다. 다리는 입구 발판을 유지하는 동안 동료가 맞은편 발판을 밟으면 고정된다. 포충기로 날아드는 파리에 맞으면 해당 도형만 안전 지점으로 복귀한다. |
| **CH7 · 조리대와 배출구** | 감지 구역의 추적 레이저를 피하고 가속 발판 2개를 지나 **E**로 열쇠를 얻는다. 열쇠를 얻은 뒤 상단 출구를 지나 배출구 착지 판정에 들어간다. | 레이저는 조준 연출이다. 조건을 충족하면 맵2 클리어 화면이 표시되고, **Next Stage**를 선택하면 팀 공식 맵3이 열린다. 멀티에서는 서버가 열쇠와 도착을 확정한다. |

## 시간과 조작

- **CH6 분류 밀대** 다음 밀대 작동 간격 기준 3.6초, 작동 전 경고 1초, 밀어내는 동작 0.8초. 출구 손잡이를 E로 당기면 바로 다음 작동만 2초 늦어진다. 같은 작동에 중복 지연을 쌓을 수 없다. [밀대 코드](../../Assets/KitchenTeamTrial/Scripts/KitchenSortingPushers.cs)
- **CH6 포충기** 벽면 포충기로 향하는 네 경로(직선 2개, 대각선 2개)의 순서는 무작위다. 비행 전 1.1초 동안 경로가 표시된다. 피격 판정은 소유 도형에 적용된다. [비행과 복귀](../../Assets/KitchenTeamTrial/Scripts/KitchenInsectFlightTrap.cs)
- **이동** 현재 씬은 도형별 지상 이동 속도에 1.65배를 적용한다. 싱글에서는 Tab으로 조작 도형을 바꾸며, 멀티에서는 각자 자기 도형을 움직인다. [이동 배율](../../Assets/KitchenTeamTrial/Scripts/KitchenTeamMovementScale.cs)
- **낙하와 피격 복귀** 일반 낙하는 체크포인트 복귀, CH2 물줄기·CH3 고온 레일·CH6 파리는 각 구간에 지정된 안전 위치를 사용한다. CH6 밀대는 접촉 시 회수 접시로 옮기는 별도 동작이다. [물줄기](../../Assets/Scenes/Map2_Kitchen/Rebuild/Scripts/KitchenSterilizer.cs) · [고온 레일](../../Assets/KitchenTeamTrial/Scripts/KitchenHotRail.cs)

## 추격·레이저 판정의 범위

쥐와 바퀴벌레는 경로를 따라 움직이며 멀티에서는 서버가 추격을 계산한다. 확인한 [추격 코드](../../Assets/Scenes/Map2_Kitchen/Rebuild/Scripts/KitchenPursuit.cs)는 접촉에 따른 포획이나 리스폰을 구현하지 않는다. [레이저 코드](../../Assets/Scenes/Map2_Kitchen/Rebuild/Scripts/KitchenWashHazards.cs)도 움직임과 시야에 따른 조준만 담당하며 피격 처리가 없다. 따라서 이 두 연출을 현재 후보의 접촉 사망 기믹으로 간주하지 않는다.

## 맵 선택과 맵3 전환

피처 브랜치의 [로비 맵 목록](../../Assets/MultiplayerSystem/MpLobby.cs)에서 맵2는 `Map2KitchenTeamTrial`이다. 이전 통합본의 맵2 선택 씬은 `Map2KitchenPlayable`이었다. 피처 브랜치의 [레벨 목록](../../Assets/LevelIntegration/Resources/LevelManager.prefab)은 맵1 → 협동 맵2 → `Assets/Scenes/Map3_ToyWorld/Scenes/Map3_ToyWorld.unity` → 맵4 순서다. [맵2 도착 판정](../../Assets/Scenes/Map2_Kitchen/Rebuild/Scripts/KitchenMapHandoff.cs)은 공통 클리어를 호출하고, [레벨 관리자](../../Assets/LevelIntegration/LevelManager.cs)의 Next Stage가 공식 맵3을 연다.
