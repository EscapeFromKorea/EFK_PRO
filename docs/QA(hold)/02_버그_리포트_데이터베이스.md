## 운영 규칙

- 한 티켓에는 한 문제만 작성합니다.
- 제목은 `[맵/구역][기능] 발생 조건과 문제` 형식으로 작성합니다.
- 최소 3회 재현을 시도하고 `n회 중 n회`로 기록합니다.
- 실제 결과와 기대 결과를 분리합니다.
- 심각도는 사용자 영향, 우선순위는 처리 시급성을 나타냅니다.
- 수정 완료 후 원래 재현 절차와 연관 기능을 모두 재테스트합니다.

## 상태 정의

| 상태 | 설명 |
|---|---|
| 신규 | 최초 등록 후 아직 분석되지 않은 상태 |
| 확인 중 | 재현·기획 의도·중복 여부를 확인하는 상태 |
| 수정 예정 | 수정 대상으로 승인되었으나 작업 전인 상태 |
| 수정 중 | 개발자가 수정하는 상태 |
| 수정 완료 | 수정 빌드가 전달되어 QA 확인을 기다리는 상태 |
| 재테스트 | QA가 수정 결과와 회귀 범위를 확인하는 상태 |
| 재오픈 | 수정 후에도 재현되거나 관련 문제가 남은 상태 |
| 종료 | 재테스트를 통과한 상태 |
| 보류 | 일정·기획·위험 수용 결정으로 현재 처리하지 않는 상태 |
| 재현 불가 | 지정 횟수만큼 확인했으나 재현하지 못한 상태 |

## 심각도·우선순위 기준

| 구분 | 기준 | 예시 |
|---|---|---|

## 작성 예시 1 — P06 팀 리프트

### `[BUG-0001][Map1/P06][TeamLiftGate] 상단 스위치를 밟아도 팀 리프트 발판이 상승하지 않음`

- 상태: 신규
- 심각도: S2 주요
- 우선순위: P1 높음
- 분류: Gameplay
- 관련 TC: M1-P06-001

#### 재현 절차

1. 정사면체로 P06 상단으로 이동합니다.
2. `P06_Tetra_TopSwitch` 중앙에 진입합니다.
3. 스위치 위에서 2초간 유지합니다.
4. `P06_TeamLiftGate`를 관찰합니다.

#### 실제 결과

- 스위치가 눌리지만 리프트 발판이 움직이지 않습니다.

#### 기대 결과

- 스위치를 밟는 동안 리프트 발판이 설정된 높이까지 상승해야 합니다.

#### 재현 정보

- 재현율: 5회 중 5회
- 우회 방법: 없음

## 작성 예시 2 — P12 최종 점프

### `[BUG-0002][Map1/P12][FinalJump] 발판 접촉 시 점프가 발동하지 않음`

- 상태: 신규
- 심각도: S2 주요
- 우선순위: P1 높음
- 분류: Gameplay
- 관련 TC: M1-P12-001

#### 재현 절차

1. 도형으로 발판 중앙에 접근합니다.
2. 위쪽에서 발판과 접촉합니다.
3. 수직 속도와 최고 도달 높이를 관찰합니다.
4. 구·정육면체·정사면체로 각각 반복합니다.

#### 실제 결과

- 발판에 접촉해도 수직 발사가 발생하지 않습니다.

#### 기대 결과

- 세 도형 모두 접촉 시 설정된 목표 높이로 발사되어야 합니다.

#### 재현 정보

- 재현율: 각 도형별 5회 중 발생 횟수를 기록합니다.
- 우회 방법: 확인 후 기록합니다.
