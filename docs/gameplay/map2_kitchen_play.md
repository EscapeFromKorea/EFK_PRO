# Map2 Kitchen 플레이 가이드

## 1. 문서 목적

이 문서는 부엌 맵의 8개 섹터를 처음부터 출구 기둥까지 진행하기 위한 플레이·QA 가이드입니다. 플레이어는 구, 정사면체, 정육면체를 동시에 조작하지 않습니다. 한 도형을 발판·레버·다리 유지 위치에 남겨 둔 뒤 `Tab`으로 조작 대상을 전환해 협동합니다.

전체 목표는 책상과 선반이 있는 시작 구역에서 출발하여 부엌을 지나 베란다의 출구 기둥 정상에 도달하는 것입니다.

## 2. 기본 조작과 공통 규칙

| 입력 | 기능 |
|---|---|
| `WASD` | 현재 조작 중인 도형 이동 |
| `Space` | 점프 |
| `Tab` | 구·정사면체·정육면체 사이의 조작 대상 전환 |
| 마우스 이동 | 카메라 회전 |
| `F` | 가까운 실/와이어 앵커에 연결 또는 연결 해제 |
| 마우스 휠 | 실 연결 중에는 실 길이 조절, 투석기 당김 줄 연결 중에는 당김 세기 조절 |
| `C` | 투석기 조작. 정사면체는 당김 줄 연결/발사, 정육면체는 버킷 탑승 |
| `R` | 현재 조작 도형을 마지막 체크포인트로 복귀 |

- 구는 빠른 이동과 와이어 이동에, 정사면체는 높은 점프와 투석기 당김·모래시계 발동에, 정육면체는 무게 유지와 바람 저항에 유리합니다.
- 유지형 발판과 다리는 그 위의 도형이 내려오면 비활성화될 수 있습니다. 반드시 발판 위 도형을 남겨 둔 뒤 `Tab`으로 전환하십시오.
- 낙사, 끼임, 위험 구간 실패 시에는 자동 복귀를 기다리거나 `R`로 마지막 체크포인트로 돌아가십시오.
- 실/와이어에는 한 번에 한 도형만 연결할 수 있습니다. 연결한 도형을 다른 도형으로 전환해도 연결은 유지되지만, 해제하려면 다시 그 도형으로 전환한 뒤 `F`를 누르십시오.

## 3. 전체 진행 요약

`S1 책상·의자·유리문 → S2 선반 투석기·벽 파괴 → S3 전등 와이어 → S4 인덕션 상승 바람 → S5 생성 다리 → S6 싱크대 낙수·창문 → S7 베란다 점프·시소 → S8 출구 기둥`

## 4. 섹터별 플레이 흐름

### S1. 책상 위 대기와 유리문 개방

목표는 구를 책상 위 대기 지점까지 올린 뒤, 의자를 이용해 선반 유리문을 여는 것입니다.

1. 구를 책상 위 대기 지점으로 이동시킵니다.
2. `Tab`으로 정사면체와 정육면체를 차례로 조작해 레버를 밉니다.
3. 두 도형이 레버 조작으로 의자를 책상/선반 쪽으로 끌어오면, 구로 전환합니다.
4. 구를 의자 위에 올린 뒤 선반 유리문을 밀어 엽니다.
5. 열린 유리문 너머 선반 계단 입구에서 세 도형을 합류시킵니다.

완료 기준: 의자가 구의 상승 경로에 도달하고, 구가 의자를 통해 유리문을 열어 다음 선반 구역으로 진입할 수 있어야 합니다.

### S2. 선반 투석기와 벽 파괴

목표는 정육면체를 투석기에 탑승시키고 정사면체가 장전·발사하여 막힌 벽을 파괴하는 것입니다.

1. 세 도형을 선반 계단으로 올려 투석기 주변에 모읍니다.
2. 정사면체를 당김 앵커 가까이 이동시켜 `C`를 눌러 당김 줄에 연결합니다.
3. 마우스 휠을 위로 굴려 투석기 팔을 충분히 당깁니다. 정육면체는 팔이 충분히 당겨진 뒤에만 탑승할 수 있습니다.
4. `Tab`으로 정육면체를 조작하고, 버킷 근처에서 `C`를 눌러 탑승시킵니다.
5. 정사면체로 다시 전환한 뒤 `C`를 눌러 당김 줄을 해제하면 투석기가 발사됩니다.
6. 정육면체가 벽을 파괴한 뒤 착지·조작 복구를 기다리고, 열린 통로에서 전원을 합류시킵니다.

완료 기준: 정사면체가 장전한 투석기에 정육면체가 탑승하고, 발사 충돌로 벽이 파괴되어 통로가 열려야 합니다.

### S3. 전등 와이어 횡단

목표는 전등을 낮춰 구가 와이어를 타고 건넌 뒤, 반대편 발판으로 팀 이동로를 여는 것입니다.

1. 구가 아닌 도형(정사면체 또는 정육면체)을 전등 하강 발판 위에 올립니다.
2. 전등이 충분히 내려오면 구로 전환합니다.
3. 구를 첫 와이어 앵커 가까이 이동시키고 `F`로 연결합니다.
4. 와이어를 따라 옆으로 이동한 뒤, 구석의 착지 지점에서 `F`로 연결을 해제합니다. 필요하면 마우스 휠로 실 길이를 조절합니다.
5. 구가 부엌 쪽 구석 발판을 밟아 다른 두 도형이 건널 수 있는 경로를 엽니다.
6. 발판 유지가 필요하면 구를 그 자리에 남긴 채 `Tab`으로 다른 도형을 전환하여 이동시킵니다.

완료 기준: 전등 하강 발판을 밟은 동안 와이어 접근이 가능하고, 구가 반대편 발판을 작동시킨 뒤 세 도형 모두 다음 구역으로 이동할 수 있어야 합니다.

### S4. 인덕션 상승 바람 우회

목표는 인덕션 위 상승 바람을 이용하거나 우회하여 세 도형을 반대편으로 넘기는 것입니다.

1. 정육면체로 전환해 인덕션 옆 발판을 밟습니다.
2. 발판이 천장 판을 아래로 내리면, 정육면체는 발판을 유지하거나 인덕션을 직접 가로질러 이동합니다.
3. 구와 정사면체는 상승 바람에 떠오르므로, 내려온 천장 판을 이용해 상부 이동 경로를 통과합니다.
4. 세 도형을 인덕션 반대편의 안전 발판에 합류시킵니다.

완료 기준: 위쪽을 향한 바람은 구·정사면체를 위로 밀고, 정육면체는 바람 영향을 받지 않아 발판 유지 역할을 수행할 수 있어야 합니다. 천장 판이 내려온 상태에서 가벼운 두 도형의 통과 경로가 확보되어야 합니다.

### S5. 생성 다리로 인덕션 구간 통과

목표는 구가 다리 생성 발판을 유지하고, 정사면체와 정육면체를 반대편으로 합류시키는 것입니다.

1. 인덕션을 먼저 넘어온 구를 다리 생성 발판 위에 올립니다.
2. 구를 발판 위에 남겨 둔 채 `Tab`으로 정사면체를 조작합니다.
3. 생성된 다리를 따라 정사면체를 반대편으로 이동시킵니다.
4. 정육면체는 생성 다리를 이용하거나, S4에서 확보한 인덕션 횡단 경로를 이용해 반대편으로 이동합니다.
5. 세 도형이 모두 도착한 뒤에만 구를 발판에서 내립니다.

완료 기준: 구가 발판을 밟는 동안 다리의 시각 요소와 콜라이더가 함께 활성화되어야 합니다. 정사면체와 정육면체가 낙하 없이 반대편에 도착해야 합니다.

### S6. 싱크대 낙수와 창문 개방

목표는 정사면체가 모래시계를 발동해 낙수를 늦추고, 구가 싱크대 아래 발판으로 창문을 여는 것입니다.

1. 정사면체로 모래시계를 밀거나 충돌시켜 발동합니다. 발동 후 낙수가 느려진 것을 확인합니다.
2. 낙수에 세 번 맞으면 사망하므로, 느려진 시간 안에 구를 싱크대 아래 창문 발판으로 이동시킵니다.
3. 구가 발판을 밟아 창문을 열면 정사면체와 정육면체를 창문 반대편으로 먼저 보냅니다.
4. 반대편의 유지 발판은 정사면체 또는 정육면체가 대신 밟습니다.
5. 구가 창문 발판에서 내려와 열린 창문을 통과합니다.

완료 기준: 정사면체의 모래시계 발동 후 낙수 속도가 감소해야 하며, 구가 창문을 열고 다른 두 도형이 반대편 발판을 유지하는 동안 세 도형 모두 창문을 통과해야 합니다.

### S7. 베란다 점프 구간과 시소

목표는 가벼운 점프 구간을 지난 뒤, 팀 하중으로 시소를 출구 플랫폼 방향으로 충분히 기울이는 것입니다.

1. 부엌에서 베란다로 넘어온 뒤, 가벼운 점프 발판을 따라 시소 입구까지 이동합니다.
2. 정육면체를 시소의 낮춰야 할 쪽 끝에 배치합니다.
3. 구와 정사면체도 같은 쪽에 올라섭니다. 한 도형만 올라가면 기울기가 부족할 수 있으므로 팀 하중을 함께 사용합니다.
4. 시소가 반대편 플랫폼 쪽으로 충분히 기울면, 먼저 한 도형을 출구 플랫폼으로 이동시킵니다.
5. 남은 도형도 순서대로 이동해 시소 반대편에서 합류합니다.

완료 기준: 시소 위 한쪽에 하중이 실리면 해당 쪽이 내려가고 반대쪽이 올라가야 합니다. 세 도형이 함께 하중을 주면 시소가 출구 플랫폼에 닿을 수 있는 제한 각도까지 기울어야 합니다.

### S8. 출구 기둥 등반

목표는 시소 반대편의 출구 기둥을 올라 정상에 도달하는 것입니다.

1. 시소를 건넌 세 도형을 출구 기둥 아래에 모읍니다.
2. 기둥의 발판과 점프 경로를 따라 한 도형씩 상단으로 이동합니다.
3. 가장 이동이 어려운 정육면체를 먼저 안전 발판까지 올려 경로가 실제로 전원 통과 가능한지 확인합니다.
4. 세 도형이 모두 기둥 정상의 출구 영역에 들어가면 완료입니다.

완료 기준: 세 도형 모두 출구 기둥 상단의 안전 지점에 도달해야 합니다. 한 도형만 도달한 상태는 완주가 아닙니다.

## 5. 완주 판정 및 QA 기록 항목

S8 출구 기둥 정상에서 세 도형이 모두 안전 지점에 도착하면 완주로 판정합니다.

결함을 기록할 때는 다음 정보를 함께 남깁니다.

- 섹터 번호와 기믹 이름
- 사용 도형 및 `Tab` 전환 전후 상태
- 마지막 체크포인트
- 투석기 장전 비율, 발사 결과, 벽 파괴 여부
- 와이어 연결·해제와 다리/발판 유지 상태
- 낙수 피격 횟수, 모래시계 발동 여부, 창문 개방 상태
- 시소 위 하중 배치, 실제 기울기, 반대편 플랫폼 도달 여부
- 재현 빈도 및 영상 또는 스크린샷
