# [맵 번호] [맵 이름] 플레이 가이드

## 1. 문서 목적

이 문서는 `[씬 경로]`의 현재 구현을 기준으로, QA와 플레이어가 시작 지점부터 최종 출구까지 직접 진행할 수 있도록 섹터별 해결 흐름과 확인 항목을 정리한 문서입니다.

이 맵은 `[단일 플레이 / 다중 도형 협동 / 기타 방식]`으로 진행합니다. `[도형 또는 캐릭터]`를 유지 장치 위에 남겨 둔 뒤 `[전환 입력]`으로 조작 대상을 바꾸는 구조라면, 해당 조건과 실패 시 복귀 방법을 반드시 명시합니다.

## 2. 기본 조작과 공통 규칙

| 입력 | 기능 |
|---|---|
| `WASD` | 현재 조작 대상 이동 |
| `Space` | 점프 |
| `Tab` | 조작 대상 전환 |
| 마우스 이동 | 카메라 회전 |
| `[입력]` | `[기믹 조작]` |
| `[입력]` | `[기믹 조작]` |
| `R` | 마지막 체크포인트로 복귀 |

- `[캐릭터/도형 A]`는 `[강점과 역할]`에 유리합니다.
- `[캐릭터/도형 B]`는 `[강점과 역할]`에 유리합니다.
- `[캐릭터/도형 C]`는 `[강점과 역할]`에 유리합니다.
- `[유지형 발판·다리·문]`은 `[유지 조건]`을 만족하는 동안만 작동합니다. 조작 대상을 전환하기 전 유지 담당을 남겨 두십시오.
- 낙사·끼임·기믹 실패 시 `[자동 복귀 조건]`을 기다리거나 `R`로 마지막 체크포인트에 복귀하십시오.

## 3. 전체 진행 요약

`S1 [시작 기믹] → S2 [기믹] → S3 [기믹] → … → S[마지막] [출구 기믹]`

## 4. 섹터별 플레이 흐름

### S1. [섹터 이름]

목표는 `[이 섹터의 최종 목표]`입니다.

1. `[시작 위치·조작 대상·첫 행동]`
2. `[기믹 작동 방법]`
3. `[다른 조작 대상의 역할]`
4. `[합류 또는 다음 섹터 진입 방법]`

완료 기준: `[다음 구역으로 진행 가능함을 확인하는 구체적 결과]`

### S2. [섹터 이름]

목표는 `[이 섹터의 최종 목표]`입니다.

1. `[행동 1]`
2. `[행동 2]`
3. `[행동 3]`
4. `[행동 4]`

완료 기준: `[완료 조건]`

### S3. [섹터 이름]

목표는 `[이 섹터의 최종 목표]`입니다.

1. `[행동 1]`
2. `[행동 2]`
3. `[행동 3]`

완료 기준: `[완료 조건]`

### S[번호]. [섹터 이름]

목표는 `[이 섹터의 최종 목표]`입니다.

1. `[행동 1]`
2. `[행동 2]`
3. `[행동 3]`

완료 기준: `[완료 조건]`

> 섹터 수에 맞춰 위 블록을 복제하거나 삭제합니다. 각 섹터에는 목표, 실제 조작 순서, 협동 유지 조건, 완료 기준을 빠짐없이 작성합니다.

## 5. 완주 판정 및 QA 기록 항목

`[최종 출구/목표 영역]`에 `[완주에 필요한 캐릭터·도형]`이 모두 도착하면 완주로 판정합니다.

결함을 기록할 때는 다음 정보를 함께 남깁니다.

- 맵·섹터 번호와 기믹 또는 오브젝트 이름
- 사용한 캐릭터/도형 및 직전 조작
- 조작 대상 전환 전후 상태
- 마지막으로 활성화한 체크포인트
- 기믹의 기대 결과와 실제 결과
- 낙사, 끼임, 이동 불가, 문 닫힘, 발판 소멸 등 실패 유형
- 재현 빈도 및 영상 또는 스크린샷
