# Map1 DayDream 플레이 가이드

## 1. 문서 목적

이 문서는 `Assets/Scenes/map1_codex.unity`의 현재 구현을 기준으로, QA가 시작 지점부터 최종 정상까지 직접 진행할 수 있도록 섹터별 해결 흐름과 확인 항목을 정리한 문서다.

Map1은 세 도형을 동시에 움직이는 방식이 아니라, 한 도형을 기믹 위에 남겨 둔 뒤 `Tab`으로 조작 대상을 바꾸는 방식으로 진행한다. 전체 동선은 시작 지점에서 대체로 `+Z` 방향이며, 각 섹터 끝의 체크포인트가 다음 섹터 진입 기준이다.

## 2. 기본 조작과 QA 유의사항

| 입력 | 기능 |
|---|---|
| `WASD` | 현재 도형 이동 |
| `Space` | 점프. 정사면체가 벽에 부착된 상태에서는 위로 도약하며 탈착 |
| `Tab` | 조작 도형 전환 |
| 마우스 이동 | 카메라 회전 |
| `F` | 가까운 실 앵커에 매달리기 또는 실 놓기 |
| 마우스 휠 | 매달린 실 길이 조절. 위로 굴리면 실이 짧아짐 |
| `G` | 정사면체 전용 핀 설치 및 벽 부착 |
| `T` | 정사면체가 설치한 핀 전부 회수 |
| `R` | 현재 조작 도형을 마지막 체크포인트로 복귀 |

- 구는 이동과 활주가 빠르고, 정사면체는 점프와 핀 설치에 유리하며, 정육면체는 무게판과 닻 역할을 담당한다.
- 실에는 한 번에 한 도형만 매달릴 수 있다. 다른 도형으로 전환해도 기존 도형의 매달림 상태는 유지된다.
- 정육면체는 일반 구간에서 무게 때문에 실에 매달릴 수 없다. P11 무중력 버블 안에서는 무게가 감소해 매달릴 수 있다.
- 체크포인트는 세 도형이 공유한다. 한 도형이 새 체크포인트를 활성화한 뒤 다른 도형에 `R`을 사용하면 앞 구간을 건너뛸 수 있으므로, 정상 동선 검증 중에는 세 도형을 모두 이동시킨 뒤 다음 체크포인트를 밟는다.
- 낙사하거나 지형에 끼었을 때는 자동 복귀를 기다리거나 `R`을 사용한다. 실에 매달렸거나 벽에 부착된 상태에서는 먼저 `F` 또는 `Space`로 해제해야 한다.

## 3. 전체 진행 요약

`P01 점프 학습 → P02 가속 점프 → P03 무게 구름 → P04 패드/레버 문 → P05 실 스윙 → P06 정사면체 벽 등반 → P07 정육면체 닻/무지개 다리 → P08 무게 문 → P09 실다리 → P10 두 종류의 무지개 다리 → P11 무중력 버블 → P12 종합 피날레`

## 4. 섹터별 플레이 흐름

### P01. 구름 사이 첫 도약

목표는 네 개의 점프 발판을 차례대로 밟아 첫 착지 섬으로 이동하는 것이다.

1. 각 도형으로 `P01_JumpPad_1`부터 `P01_JumpPad_4`까지 순서대로 밟는다.
2. 발판 위에서 별도의 점프 입력을 연타하기보다 발사 방향을 유지해 다음 스텝 중앙에 착지한다.
3. 마지막 발판에서 `P01_Landing_Island`로 이동한다.
4. 세 도형을 모두 옮긴 뒤 `Checkpoint_P01`을 활성화한다.

완료 기준: 착지 섬의 체크포인트가 활성화되고 P02 활주로로 이동할 수 있어야 한다. 도형의 질량과 관계없이 점프 발판의 목표 높이가 일정한지도 확인한다.

### P02. 잠에 취한 활주로

목표는 가속 발판의 속도를 유지한 채 점프대로 진입해 도형별 착지대로 건너가는 것이다.

1. 활주로 중앙의 `P02_Accel`을 `+Z` 방향으로 밟는다.
2. 가속된 상태로 직진해 `P02_Launch`에 진입한다.
3. 정육면체는 가까운 왼쪽 착지대, 정사면체는 중앙 착지대, 구는 먼 오른쪽 착지대를 목표로 한다.
4. 각 착지대에서 합류 섬으로 이동한다. 높이가 부족하면 `P02_ReunionAssist`를 이용한다.
5. `Checkpoint_P02`에서 세 도형을 합류시킨다.

완료 기준: 세 도형이 각자의 착지 경로를 거쳐 `P02_Reunion`에 도착해야 한다. 가속이 끝난 뒤에는 이동 속도가 정상적으로 원복되어야 한다.

### P03. 잠들지 않는 구름

목표는 도형의 무게 차이에 맞는 두 경로를 이용해 구름 강을 통과하는 것이다.

1. 구와 정사면체는 중앙의 `P03_Cloud_1`부터 `P03_Cloud_8`까지 연속으로 이용한다.
2. 구름이 눌린 직후 다음 구름 방향으로 이동 입력을 주어 튕김을 연결한다.
3. 정육면체는 구름을 밟으면 눌러앉거나 붕괴시킬 수 있으므로, 오른쪽의 `P03_CubeStone_1~9`를 따라 이동한다.
4. 두 경로 끝의 `P03_Exit`에서 다시 합류한다.

완료 기준: 구와 정사면체는 구름의 반발을 받고, 정육면체는 별도 디딤돌 경로로 `Checkpoint_P03`까지 도착해야 한다. 붕괴한 구름은 일정 시간 후 복구되어야 한다.

### P04. 처음 손을 잡다

목표는 `P04_HoldPad`와 `P04_LeverHead`를 이용해 세 도형을 문 반대편으로 보내는 것이다.

1. 한 도형을 `P04_HoldPad` 위에 세워 둔다. 패드를 밟고 있는 동안 `P04_Door`가 열려야 한다.
2. `Tab`으로 전환해 나머지 두 도형을 열린 문 너머 `P04_Exit` 쪽으로 이동시킨다.
3. 다시 패드 위 도형으로 전환한 뒤 패드에서 내려온다.
4. `P04_LeverHead`를 문 방향으로 밀어 충분히 회전시키고, 문이 열린 동안 마지막 도형을 통과시킨다.
5. 레버에서 접촉을 떼면 약 5초 후 레버가 원위치로 복귀하기 시작하며, 비활성화되면 문도 닫혀야 한다.

완료 기준: 시작 시 문이 닫혀 있고, 패드는 밟는 동안만 문을 열며, 레버는 실제로 미는 방향으로 움직여야 한다. 세 도형이 모두 문을 지난 뒤 `Checkpoint_P04`에 도착하면 완료다.

### P05. 꿈에서 꿈으로

목표는 가벼운 두 도형은 실 스윙으로, 정육면체는 오른쪽 우회로로 협곡을 통과하는 것이다.

1. 구 또는 정사면체로 첫 스윙 앵커 가까이 이동한 뒤 `F`를 눌러 매달린다.
2. `WASD`로 진폭을 키우고 필요하면 마우스 휠로 실 길이를 조절한다.
3. 다음 착지 지점을 향하는 순간 `F`로 놓고, `P05_SwingAnchor_1~5`를 차례대로 이용한다.
4. 실에는 한 번에 한 도형만 매달릴 수 있으므로 구와 정사면체를 순서대로 이동시킨다.
5. 정육면체는 오른쪽의 `P05_Cube_Bypass_1~9` 디딤돌을 따라 이동한다.
6. `P05_Reunion`에서 세 도형을 합류시킨다.

완료 기준: 정육면체는 일반 상태에서 실 연결이 거절되고, 구와 정사면체는 스윙 속도를 보존한 채 실을 놓을 수 있어야 한다. 세 도형이 `Checkpoint_P05`에 도착하면 완료다.

### P06. 몽유의 벽

목표는 정사면체로 벽을 오른 뒤 상단 스위치를 작동시켜 팀 경로를 여는 것이다.

1. 정사면체로 `P06_ClimbWall`을 바라보며 접근한다.
2. 벽이 핀 사거리 안에 들어오면 `G`를 눌러 핀을 설치하고 벽에 부착한다.
3. 부착 상태에서 `Space`로 위로 도약하고, 공중에서 벽 쪽으로 이동한 뒤 다시 `G`를 눌러 더 높은 위치에 부착한다.
4. 핀은 최대 두 개까지 유지된다. 잘못 설치했다면 `T`로 회수하고 다시 시도한다.
5. 같은 과정을 반복해 `P06_Top`에 오른 뒤 `P06_Tetra_TopSwitch`를 밟아 `P06_TeamLiftGate`를 연다.
6. `Tab`으로 나머지 도형을 전환해 열린 팀 경로로 이동시키고, 이후 `P06_Descent_1~4`를 통해 다음 구간으로 내려간다.

완료 기준: 정사면체만 핀을 설치할 수 있고 상단 스위치가 팀 게이트를 열어야 한다. `Checkpoint_P06` 활성화 후 P07 입구로 이동할 수 있어야 한다.

현재 구현 참고: 다른 두 도형을 상단까지 직접 운반하는 이동 리프트는 아직 없다. 팀 게이트와 하강 스텝으로 합류 흐름만 구성된 블록아웃이므로, 나머지 도형의 합류 동선이 막히면 재현 위치와 도형을 결함 기록에 남긴다.

### P07. 잠든 거인 깨우기

목표는 정육면체를 닻으로 활용하고 Hold 방식 무지개 다리로 팀을 건너보내는 것이다.

1. 정육면체를 `P07_Cube_Pedestal` 위에 멈춰 세운 뒤 다른 도형으로 전환한다. 조작하지 않는 정육면체가 닻으로 인식되어야 한다.
2. 가벼운 도형 한 개를 오른쪽의 `P07_Cube_ReturnBridge` 스위치 위에 남겨 무지개 다리를 활성화한다.
3. `Tab`으로 정육면체와 다른 도형을 전환해 활성화된 다리를 건넌다.
4. 스위치에 남은 마지막 가벼운 도형은 `P07_CatchAnchor` 가까이 이동해 `F`로 매달린 뒤 스윙하여 `P07_Landing`으로 건넌다.

완료 기준: 조작하지 않고 정지한 정육면체가 닻으로 동작하고, 무지개 다리는 스위치를 밟는 동안만 보이며 충돌체가 활성화되어야 한다. 세 도형이 `Checkpoint_P07`에 도착하면 완료다.

### P08. 저울에 오른 꿈

목표는 정육면체의 무게로 문을 유지하고, 정육면체는 별도 우회로로 합류하는 것이다.

1. 정육면체를 `P08_WeightPlate` 위에 올린다. 무게가 기준값 2.75를 넘으면 `P08_WeightDoor`가 열린다.
2. 정육면체를 판 위에 둔 채 `Tab`으로 구와 정사면체를 전환해 문 너머로 이동시킨다.
3. 다시 정육면체로 전환해 무게판에서 내려온다. 이 문은 고정형이 아니므로 판에서 벗어나면 닫혀야 한다.
4. 정육면체는 문 오른쪽의 `P08_Cube_Bypass_1~6` 디딤돌을 따라 `P08_Reunion`으로 이동한다.

완료 기준: 가벼운 도형만 무게판에 올렸을 때는 문이 열리지 않고, 정육면체가 내려오면 문이 다시 닫혀야 한다. 세 도형이 `Checkpoint_P08`에 도착하면 완료다.

### P09. 꿈결 위의 줄다리

목표는 두 섬 사이에 놓인 실다리를 건너는 것이다.

1. `P09_WeightedThreadBridge` 중앙에 맞춰 한 도형씩 이동한다.
2. 여러 도형을 한곳에 겹치기보다 간격을 두고 순서대로 건너 실의 처짐과 흔들림을 줄인다.
3. 세 도형을 `P09_Exit`으로 이동시킨다.

완료 기준: 도형이 올라가면 실다리가 무게에 반응해 처지고, 내려오면 안정되어야 한다. `Checkpoint_P09`에 도착하면 완료다.

현재 구현 참고: 두 앵커와 실다리는 이미 연결되어 있다. 정사면체가 핀 두 개를 설치해야 다리가 생성되는 생산형 조건은 아직 구현되지 않았으므로, 핀 설치 없이 건널 수 있는 것이 현재 기준에서는 정상이다.

### P10. 꿈에만 보이는 다리

목표는 왼쪽 협동 다리 또는 오른쪽 시간제한 다리를 이용해 합류 섬으로 건너는 것이다.

- 왼쪽 `P10_CoopBridge`: 한 도형이 스위치 위에 있는 동안만 다리가 유지된다. 도형 하나를 스위치에 남기고 다른 도형들을 먼저 건넌다.
- 오른쪽 `P10_TimedBridge`: 스위치를 밟으면 다리가 나타나며, 스위치에서 내려온 뒤에도 약 3.5초 동안 유지된다. 작동 직후 멈추지 말고 끝까지 달린다.

세 도형을 모두 이동시키는 권장 순서는 다음과 같다.

1. 한 도형이 왼쪽 스위치를 유지하고 다른 두 도형을 협동 다리로 건넨다.
2. 마지막 도형은 오른쪽 시간제한 스위치를 작동시킨 뒤 3.5초 안에 다리를 건넌다.
3. `P10_Reunion`에서 합류한다.

완료 기준: 왼쪽 다리는 Hold 상태에만 유지되고, 오른쪽 다리는 스위치에서 내려온 뒤 설정 시간 후 사라져야 한다. `Checkpoint_P10`에 도착하면 완료다.

### P11. 안개 낀 기류

목표는 무중력 버블에서 달라지는 중력과 무게를 이용해 연속 구간을 통과하는 것이다.

1. 구와 정사면체는 `P11_Bubble_1~3` 안으로 진입해 점프하거나 `P11_BubbleAnchor_1~3`에 `F`로 매달려 이동한다.
2. 정육면체도 버블 안에서는 무게가 감소하므로 앵커 연결을 시도해 본다. 버블 밖으로 나가 무게가 복구된 상태가 계속되면 실이 끊어져야 한다.
3. 안정적인 진행이 필요하면 정육면체는 아래의 `P11_FloorSafety`를 따라 이동한다.
4. 세 도형을 `P11_Exit`으로 이동시킨다.

완료 기준: 버블 진입 시 도형별 중력과 점프 반응이 달라지고, 이탈 시 정상값으로 복원되어야 한다. 정육면체의 버블 내부 실 연결과 외부 이탈 시 끊김을 확인한 뒤 `Checkpoint_P11`에 도착한다.

### P12. 꿈의 정점

목표는 축소 통로, 벽 등반, 최종 점프를 차례대로 사용해 정상에 도착하는 것이다.

1. 각 도형으로 `P12_ShrinkPad`를 한 번씩 밟아 축소 상태로 만든다.
2. 폭이 좁은 `P12_TunnelWall_L/R` 사이를 지나 `P12_Mid`로 이동한다. 패드는 토글 방식이므로 다시 밟으면 원래 크기로 돌아간다.
3. 정사면체는 P06과 동일하게 `G → Space → G` 순서로 `P12_FinalClimbWall`을 올라간다. 필요하면 생성된 핀과 `P12_ClimbMarker_Low/High`를 실 연결 지점으로 활용한다.
4. 상단의 `P12_UpperDeck`으로 이동한 뒤 `P12_FinalJump`에 진입한다.
5. 정상의 `P12_Summit`에 착지해 `Checkpoint_P12`를 활성화한다.

완료 기준: 기본 크기로는 좁은 통로 통과가 어렵고 축소 후 통과할 수 있어야 한다. 정사면체의 핀 설치와 벽 부착이 정상 동작하고, 최종 점프대로 정상까지 도달할 수 있어야 한다.

현재 구현 참고: P12는 종합 피날레 블록아웃 단계다. 생성 코드와 설계 문서에는 무게 문과 최종 가속 발판이 정의되어 있지만, 현재 씬에는 `P12_WeightPlate`, `P12_WeightDoor`, `P12_FinalAccel`이 배치되어 있지 않다. 따라서 현재 QA 기준에서는 이 기믹들을 필수 진행 조건으로 보지 않는다. 세 도형의 역할을 모두 사용하지 않으면 절대 통과할 수 있도록 완전히 봉쇄되어 있지 않고, 다른 도형을 상단으로 합류시키는 동선과 구간 내부 체크포인트도 완성되지 않았다. 의도한 순서로 진행할 수 없는 지점이 있으면 임의 우회보다 도형, 위치, 직전 행동을 기록한다.

## 5. 완주 판정 및 QA 기록 항목

정상의 `Checkpoint_P12`를 활성화하고 무지개 아치와 달·별 기둥이 있는 정상 섬에 도착하면 현재 구현 범위의 완주로 본다.

결함을 기록할 때는 다음 정보를 함께 남긴다.

- 섹터 번호와 오브젝트 이름
- 사용한 도형과 직전 조작
- `Tab` 전환 전후의 상태
- 마지막으로 활성화한 체크포인트
- 낙사, 끼임, 문 닫힘, 실 끊김 등 실제 결과
- 재현 빈도와 재현 영상 또는 스크린샷

특히 P06의 팀 합류 경로, P09의 생산형 조건, P12의 세 도형 필수 동선은 현재 미완성 범위와 실제 회귀 결함을 구분해서 기록한다.
