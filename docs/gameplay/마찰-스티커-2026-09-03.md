## 무엇인가

플레이어가 표면에 스티커를 붙였다 떼어 그 표면의 **마찰력을 바꾼다.**

| 종류 | 효과 | 조준점 색 |
|---|---|---|
| 미끄럼 (Slip) | 마찰 감소 → 경사 가속, 블록 운반, 레일카 가속 | 파랑 |
| 벨크로 (Velcro) | 마찰 증가 → 경사 정지, 블록 고정, 레일카 제동 | 주황 |

## 조작

근접 방식이다 — **카메라 조준 안 한다.**

- 플레이어가 `StickerSurface`가 붙은 표면에 **4칸(aimRange) 안**으로 다가가면 그 표면 위에 색깔 조준점(구)이 뜬다.
- **`V`** : 조준점 색대로 부착. 이미 다른 종류가 붙어 있으면 교체(회수 먼저 안 해도 됨). 같은 종류가 붙어 있으면(조준점 흰색) 회수.
- **`Q`** : 미끄럼 ↔ 벨크로 선택 전환.
- (`F`·`G`는 꿈의 실타래가 쓰고 있어서 `V`를 쓴다.)

## 어떻게 동작하나

### 파일 (`Assets/FrictionStickerSystem/`)

| 파일 | 역할 |
|---|---|
| `StickerSurface.cs` | 부착 허용 표면 마커. 허용 종류(`allowSlip`/`allowVelcro`) + "표면당 스티커 1개" 슬롯(`Current`). 콜라이더 보유 오브젝트에 붙인다. |
| `FrictionSticker.cs` | 런타임 생성되는 스티커. 대상 콜라이더의 `sharedMaterial`을 **인스턴스 `PhysicMaterial`로 교체**하고, 회수/파괴 시 원본으로 복구. 종류 색 데칼 표시. |
| `FrictionStickerSettings.cs` | 종류별 마찰값·조합방식·색·크기 튜닝 뭉치. |
| `PlayerStickerCarrier.cs` | 플레이어에 런타임 `AddComponent`. 근접 타겟팅 + 입력 + 조준점. |
| `FrictionStickerController.cs` | 씬 진입점. `RuntimeInitializeOnLoad`로 자동 생성(씬에 안 놔도 동작). 튜닝값 노출 + 플레이어에 캐리어 배선. |
| `Editor/FrictionStickerMenuItem.cs` | `Tools > FrictionStickerSystem >` 생성 메뉴. |
| `Editor/FrictionTestPlaygroundMenuItem.cs` | `Create Friction Test Playground` — 30° 경사 테스트 리그. |

### 마찰 차이가 "확연히" 나는 원리

접촉 시 실제 마찰은 두 콜라이더의 `PhysicMaterial` 중 **우선순위 높은 `frictionCombine`** 으로 정해진다 (`Maximum > Multiply > Minimum > Average`). 플레이어 재질은 `Average`라:

- **미끄럼 = `Multiply`** → 플레이어마찰 × slipFriction(0.05). 플레이어의 `Average`를 이겨서 확실히 미끄럽다.
- **벨크로 = `Maximum`** → max(플레이어마찰, velcroFriction=1.2). 확실히 잡힌다.

### Inspector 튜닝 (`FrictionStickerController`)

`slipFriction` / `slipCombine` / `velcroFriction` / `velcroCombine` / 색상 / 데칼 크기·두께 / `aimRange` / 키.

## 플레이테스트 결과 (2026-09-03, Unity 2022.3.62f3)

- **정육면체**: 미끄럼 스티커 경사 → 못 올라가고 미끄러짐 / 벨크로 → 쑥쑥 그립하며 올라감. **확연히 다름.**
- **구**: 미끄럼 → 빠르게 활강 / 벨크로 → "걸리는 느낌"으로 느려짐(구는 굴러서 완전 정지는 안 됨 — 물리적으로 정상. "정지"는 블록·미끄러지는 물체 대상).
- 부착/교체/회수, `Q` 종류 전환, 조준점 색, 마찰 원복 모두 동작. Console 에러 없음.
- **완료조건 "같은 경사면에서 일반/미끄럼/벨크로 결과가 확연히 다르다" 만족.**

## 규약 준수

- 전역 상태(`Physics.*`) 미변경 (MP-01). 콜라이더 인스턴스 재질만 건드림.
- 회수 / `OnDestroy` 에서 원본 재질 복구 (MP-05).
- 공유 `PhysicMaterial` 에셋 무오염 (인스턴스화).
- `PlayerSystem` 파일·`SampleScene` 무수정 — 캐리어는 런타임 `AddComponent`.

## 미해결 / 후속

- **중첩 규칙 미확정**: 명세서에 "같은 위치 다중 스티커 중첩 규칙을 정한다"만 있고 값 없음. 현재 "표면당 1개, 새로 붙이면 교체"로 임시 구현. `StickerSurface.Current` 슬롯 + `FrictionSticker.Attach` 교체 로직만 바꾸면 규칙 변경 가능.
- 부착 대상 명세(바닥/블록/시소/레일카/회전판) 중 시소·레일카는 아직 코드에 없음. 스티커는 대상 독립적이라 그 시스템 생기면 `StickerSurface`만 붙이면 됨.
- 결합 지점을 표면 콜라이더 하나로 봄. 표면이 여러 면이면 가장 가까운 점 기준.
