## 무엇인가

블록끼리 **면을 맞대 강접합**해서 계단·다리·경사로·추 같은 구조물을 즉석에서 만드는 기믹. 결합·해제 가능.

## 조작

근접 방식이다 — **카메라 조준 안 한다.**

- 플레이어가 `SnapBlock` 4칸(aimRange) 안으로 다가가면 그 블록이 대상이 된다.
- 대상 블록의 6면 중 다른 블록의 면과 **거리(`snapDistance` 0.6) + 각도(`snapAngleTolerance` 20°, 법선 정반대)** 조건을 통과하는 가장 가까운 면 쌍에 **초록 구 하이라이트** 2개.
- **`E`** : 대상 블록에 결합이 없으면 → 후보와 결합(자동 정렬). 결합이 있으면 → 그 블록만 구조물에서 분리(`DetachAll`).

## 어떻게 동작하나

### 파일 (`Assets/SnapBlockSystem/`)

| 파일 | 역할 |
|---|---|
| `SnapBlock.cs` | 블록 하나. `Rigidbody` + `BoxCollider` 필수. 박스 6면을 bounds에서 계산. `Weld`/`DetachFrom`/`DetachAll` + 양쪽 대칭 연결 그래프. |
| `SnapBlockController.cs` | 씬 진입점. `RuntimeInitializeOnLoad` 자동 생성. 근접 타겟팅 + 후보 탐색 + 하이라이트 + 키. |
| `Editor/SnapBlockMenuItem.cs` | `Tools > SnapBlockSystem >` 블록/컨트롤러 생성 메뉴. |

### 결합 = all-locked ConfigurableJoint + projection

`FixedJoint` 대신 `ConfigurableJoint` 전 축 `Locked` + `projectionMode = PositionAndRotation`. 조인트가 규정 위치/자세에서 벗어나면 하드로 되돌려 **"Joint 폭주"를 억제**한다. (저장소 관례 — DreamThreadController도 ConfigurableJoint.)

### 폭주 억제 3종

1. **결합 직전 정렬 포즈 스냅** — 대상 블록을 상대 면에 정확히 맞춘 자세로 회전+이동. 초기 침투가 조인트를 튀게 하는 가장 큰 원인이라 이걸 없앤다 (`SnapBlock.AlignTo`).
2. `solverIterations` 20 + `ContinuousDynamic` + `Interpolate`.
3. 결합 순간 양쪽 `velocity`/`angularVelocity` 0.

`jointBreakForce`/`Torque` Inspector 노출 (기본 무한 = 안 부서짐).

### 구조물 크기 제한

`maxBlocksPerStructure`(기본 12). 결합 전 BFS로 후보 구조물 블록 수를 세어 초과 시 거부 + Console 로그.

## 플레이테스트 결과 (2026-09-03, Unity 2022.3.62f3)

- 블록 A를 블록 B에 밀어붙이면 **초록 구 하이라이트** 표시.
- **`E`** → 블록 A가 정렬되며 B에 **딱 결합.**
- 3개로 구조물(계단/벽) 조립 → **폭주·과진동 없이 안정.**
- 결합된 블록 근처에서 `E` → 그 블록만 **분리.**
- `Max Blocks Per Structure`를 3으로 낮추고 4개째 결합 시도 → **거부 + Console 로그.**
- Console 빨간 에러 없음.
- **완료조건 "결합 후 전체 구조물이 자연스럽게 움직인다", "구·정육면체·정사면체 모두 구조물 이용" 방향 만족** (밟고 지나가기는 물리로 자동).

## 미해결 / 후속

- **Joint 폭주는 완화지 100% 보장이 아니다.** 블록이 아주 많거나 무거운 도형이 세게 부딪히면 여전히 흔들릴 수 있음. 그레이박스에서 `solverIterations`/`projectionDistance`/질량 실측 튜닝 필요. (3개 규모에선 안정 확인.)
- `AlignTo`가 `Quaternion.FromToRotation`이라 면 법선만 맞추고 roll(면 둘레 회전)은 근사. 플레이어가 대충 맞춰 민 상태 전제.
- 결합 지점 = 박스 6면 한정. 비박스 블록은 범위 밖.
- 구·정사면체를 블록으로 **결합**하는 건 안 함(블록은 별도 박스 오브젝트). 그 도형들이 구조물을 **이용**(밟기)하는 건 물리로 성립.
