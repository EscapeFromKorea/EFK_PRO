# 자유 회전 장난감 판 (Rotating Plate) — 구현 기록

> 작성 mnppi · 2026-09-03 · 담당자 mnppi

> 관련 이슈: #71 (완료) · 노션 전체명세서 "자유 회전 장난감 판"
> 데모 씬: `Assets/Scenes/GimmickDemo_mnppi.unity`

## 무엇인가

플레이어가 **밀거나 부딪혀** 임의 각도로 돌리고, 그 각도에서 멈춰 **지형(경사로·다리·임시벽·발사대)처럼** 쓰는 회전판.

## 어떻게 동작하나

### 파일 (`Assets/RotatingPlateSystem/`)

| 파일 | 역할 |
|---|---|
| `RotatingPlate.cs` | 회전판 본체. `Rigidbody` + `HingeJoint` 필수. |
| `Editor/RotatingPlateMenuItem.cs` | `Tools > RotatingPlateSystem > Create Rotating Plate` — 판 + RB + HingeJoint + 와이어 앵커 2개 배선 생성. |

### 핵심 설계 — HingeJoint (모터·스프링 없음)

- **스프링 없음** → 목표 각도로 되돌아가지 않는다 → `0°`·`90°` 스냅 없이 **민 각도 그대로 유지**. (명세서: "지정 각도 스냅 금지 → 임의 각도 유지")
- **모터 없음** → 강제 회전 안 함 → 플레이어 밀기·충돌로만 돈다.
- `connectedBody = null` → 조인트 앵커 지점이 축.
- 회전은 전부 PhysX가 처리 → 플레이어 밀기, 쐐기·블록으로 정지 모두 **코드 없음.**

### Inspector (`RotatingPlate`)

| 필드 | 매핑 |
|---|---|
| `rotationAxis` | `HingeJoint.axis` (로컬). 기본 `(1,0,0)` = 시소식 |
| `useLimits` + `minAngle`/`maxAngle` | `HingeJoint.limits` — 각도 범위 제한(스냅 아님) |
| `angularResistance` | `Rigidbody.angularDrag` — 회전 저항 |
| `maxAngularSpeedDeg` | `Rigidbody.maxAngularVelocity` (deg→rad) |
| `plateUseGravity` | 기본 off = 민 각도 유지 / on = 무게로 처짐 |

### 태엽 축 연동 스텁

```csharp
public void ApplyDriveTorque(float torqueNm)   // 외부(태엽 축)가 매 FixedUpdate 호출
public Vector3 HingeAxisWorld { get; }          // 토크 방향
```
태엽 동력 회전은 `태엽 축` 기믹(송원석, 미착수) 담당. 이 시스템은 진입점만 노출한다. 태엽 축 나오면 그쪽에서 이 둘만 호출하면 배선 끝.

### 와이어 앵커

메뉴가 판의 자식으로 `ThreadAnchor`(DreamThreadSystem) 마커 2개를 배선. `DreamThreadController`의 진자 피벗이 연결 시점 월드 좌표 스냅샷이라, 연결 후 판이 돌아도 물리가 발산하지 않는다. (피벗이 판을 따라 회전하는 건 후속.)

## 플레이테스트 결과 (2026-09-03, Unity 2022.3.62f3)

- 도형으로 판 끝을 밀면 **힌지 축 기준 시소처럼 회전.**
- 밀기 멈추면 **그 각도에 그대로 유지** (원위치 복귀 없음, 특정 각도 스냅 없음). 여러 각도 반복 확인.
- 판 밑에 정육면체 밀어넣으면 **회전이 물리로 막힘.**
- Inspector `Use Limits` + Min/Max Angle → 범위 밖 회전 차단, 범위 안은 자유.
- Console 에러 없음 (`Setting angular velocity of a kinematic body` 경고도 안 뜸 — RotatingPlate는 kinematic도 angularVelocity도 안 씀).
- **완료조건 "서로 다른 임의 각도에서 실제 발판으로 사용 가능" 만족.**

## 규약 준수

- 전역 `Physics.*` 미변경 (MP-01). 이 `Rigidbody`만 건드림.
- 모든 수치 Inspector 노출.
- `PlayerSystem`·`SampleScene` 무수정.

## 미해결 / 후속

- **태엽 동력 회전**: `태엽 축`(송원석, "시작 전") 나오면 `ApplyDriveTorque()`로 배선.
- **정사면체 쐐기로 회전 정지**: `세모 쐐기 고정`(송원석) 나오면 "쐐기 콜라이더가 회전판 정지장치 역할" 실측 확인. 현재는 임의 콜라이더가 물리로 막는 것으로 충분히 성립.
- **와이어 피벗 판 추종**: `DreamThreadController` 수정(교차 폴더)이 필요해 별도 논의 대상.
- HingeJoint 파라미터(회전 저항 1.5 / 최대 각속도 360°/s / limit ±45~75°)는 레벨에서 튜닝.
