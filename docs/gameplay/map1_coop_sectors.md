# 맵 1 DayDream 협동 구간 안내

`Map1_DayDream`의 P05·P06·P07·P09는 지정된 장치를 작동시킨 뒤 **세 도형이 체크포인트에 합류하면** 저장됩니다. 사각 타일 중앙의 원·정사각형·삼각형은 담당 도형을 나타냅니다. 해당 도형으로 밟으면 표시가 녹색으로 바뀝니다.

싱글플레이에서 `Tab`은 도형 전환, `Space`는 점프입니다. 앵커 근처에서 `E`를 짧게 눌러 실에 매달리거나 놓습니다. 정사면체는 벽을 바라보고 가까이 접근해 `E`로 핀을 꽂습니다. 벽에 붙은 상태에서 `Space`로 도약하고 다시 `E`를 눌러 더 높은 위치에 붙습니다.

## P05 · 실 스윙 협곡

정육면체의 반복 디딤돌을 **화물 발판과 도킹 부두**로 교체했습니다. 기존 스윙 경로에는 중간 선반과 합류 램프를 추가했습니다.

1. **정육면체**로 오른쪽 부두의 사각형 호출 발판을 밟습니다. 구름 받침이 있는 화물 발판이 도착하면 탑승합니다.
2. **구**로 실 앵커를 타고 중간 돌 선반에 착지합니다. 원형 발판을 밟으면 정육면체가 탑승한 화물 발판이 맞은편 부두로 이동합니다.
3. **정사면체**로 높은 돌 선반에 도달해 삼각형 발판을 밟습니다. 구와 정육면체는 맞은편 부두에서 새로 열린 램프를 건너고, 정사면체도 끝쪽 착지대로 내려옵니다.
4. 세 도형을 `Checkpoint_P05`에 모읍니다.

## P06 · 몽유의 벽

기존 등반 벽 옆에 **구의 전원 섬과 두 도형이 타는 리프트**를 추가했습니다. 리프트 위쪽의 나무 통로는 기존 상단 착지대로 이어집니다.

1. **구**는 왼쪽 화살표 가속대에서 점프해 전원 섬으로 건너갑니다. 원형 발판을 밟으면 복귀 발판이 열립니다.
2. **정육면체**는 벽 아래 오른쪽의 사각형 발판을 밟아 리프트 잠금을 풉니다.
3. **정사면체**는 벽에 핀을 꽂고 도약하며 올라 상단 삼각형 발판을 밟습니다. 세 장치를 준비하는 순서는 바꿀 수 있습니다.
4. 구와 정육면체가 모두 구름 리프트에 탑승하면 상승합니다. 나무 통로를 따라 `Checkpoint_P06`에 합류한 뒤 기존 하강로로 내려갑니다.

## P07 · 잠든 거인 깨우기

중앙의 낮은 발판을 비활성화해 **구의 낮은 스윙 선반, 정사면체의 높은 핀 벽, 정육면체가 건너는 무지개 다리**의 역할을 분리했습니다.

1. **정육면체**를 입구의 닻 받침대에 올리고 멈춘 뒤 조작을 전환합니다.
2. **구**로 정육면체 근처에서 `E`를 눌러 매달립니다. 스윙해 낮은 돌 선반을 거쳐 맞은편 원형 발판을 밟습니다.
3. **정사면체**는 중앙 앵커로 건넌 뒤 높은 돌벽을 핀과 점프로 오릅니다. 벽 위 삼각형 발판을 밟으면 무지개 다리가 고정됩니다.
4. **정육면체**로 무지개 다리를 건넙니다. 정사면체도 벽 위에서 출구 착지대로 내려와 `Checkpoint_P07`에 합류합니다.

## P09 · 역풍 터널

실다리와 핀 장치를 **역풍 터널, 바람 제단, 상승 기류**로 교체했습니다. 나무 데크와 문은 통과로를, 바람줄기와 구름·수정 제단은 기류 방향과 목적지를 표시합니다.

1. **정육면체**로 중앙 나무 통로에서 역풍을 거슬러 걸어갑니다. 끝의 사각형 무게판을 밟으면 측면 문이 열리고 가속대가 나타납니다.
2. **구**로 측면 가속대에서 점프해 잔디 섬에 들어갑니다. 바람 제단 앞 원형 발판을 밟으면 역풍이 멈추고 상승 기류가 켜집니다.
3. **정사면체**는 중앙 통로의 열린 난간 쪽에서 상승 기류 안으로 점프합니다. 높은 제단 착지대의 삼각형 발판을 밟으면 최종 문과 구의 복귀로가 열립니다.
4. 구는 측면 섬의 새 나무 통로로 복귀합니다. 정사면체도 높은 착지대 아래로 내려와 세 도형을 `Checkpoint_P09`의 출구 바닥에 모읍니다.

## 에셋 위치

잔디 받침, 돌 선반, 나무 통로, 구름 운반대와 바람 제단은 `Assets/Models`의 DayDream 원본을 조합한 프리팹입니다. 프리팹은 `Assets/Scenes/Map1_DayDream/DayDreamCoopArt`에 있으며, 스위치 표시는 씬의 플레이어 메시를 재사용합니다. 에디터의 **Tools > Map1 Codex > Apply Sector Art**로 같은 배치를 다시 적용할 수 있습니다.
