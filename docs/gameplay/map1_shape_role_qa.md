# 맵1 도형별 역할 확인

확인 필요 · 담당자 / 교차검증

목적은 세 도형이 각각 진행에 필요한 역할을 맡는지 확인하는 것입니다. P05·P06·P07·P09는 담당 도형의 기믹을 생략해도 통과할 수 있는지 함께 봅니다. 싱글은 `Tab`으로 도형 전환, `E`로 실 연결·해제와 핀 설치, `Space`로 점프합니다.

- [ ] P03 무게 구름 — 구·세모는 반발, 네모는 눌러앉아 오른쪽 디딤돌로 우회. 과부하로 무너진 구름이 복구되는지 확인.
- [ ] P05 실 스윙 — 네모가 화물 발판을 불러 탑승 → 구가 실로 중간 선반에 가서 발판 출발 → 세모가 높은 선반에서 합류 램프 개방.
- [ ] P06 팀 리프트 — 구가 전원 섬에서 복귀로 개방, 네모가 리프트 잠금 해제, 세모가 핀으로 올라 상단 스위치 작동. 세 장치를 켜고 구·네모가 함께 타면 첫 운행 시작.
- [ ] P07 네모 닻과 무지개 다리 — 네모를 닻으로 세워 구가 낮은 선반을 건넘 → 세모가 높은 핀 벽 위에서 다리 개방. 스위치에서 내려와도 다리가 유지되고, 네모가 중앙 낮은 길로 건너뛸 수 없는지 확인.
- [ ] P08 무게판 문 — 기준 `2.5`. 네모 단독 또는 구·세모가 같은 판을 함께 밟으면 열림. 구·세모 각각 단독으로는 열리지 않고, 기준 미만이면 닫힘.
- [ ] P09 역풍 터널 — 네모가 역풍을 뚫고 측면 문·가속대 개방 → 구가 섬에서 역풍을 끄고 상승 기류 작동 → 세모가 높은 제단에서 출구와 구의 복귀로 개방. 섬에서 출구로 바로 건너뛸 수 있는지 확인.
- [ ] P10 협동·시간제 다리 — 왼쪽은 스위치를 누르는 동안 유지, 오른쪽은 스위치를 밟고 작동한 시점부터 약 3.5초 유지.
- [ ] P11 무중력 버블 — 도형마다 점프·낙하가 달라지고, 버블 밖에서는 원래대로 돌아오는지 확인. 네모는 안에서 실에 연결되고, 나온 뒤 무게가 돌아오면 끊김.
- [ ] P12 정상 — 축소 패드 토글 → 세모 핀 등반 → 최종 점프. `Checkpoint_P12`는 저장, `P12_Summit_Crown` 통과는 클리어.
- [ ] 체크포인트 공유 — 도형 하나가 새 체크포인트에 도착하면 다른 도형도 `R`로 복귀 가능. 역할 확인 때는 나머지 도형도 직접 이동.

미완성 확인 — P12 무게 문·최종 가속 발판·세 도형 필수 합류 조건.

기록 — 구간 / 통과·실패·미완성 확인 / 사용 도형과 막힌 위치 / 테스트 빌드.
